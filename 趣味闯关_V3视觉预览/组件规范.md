# V3 组件规范

以375×812px为基准，适配320与430px。内容宽度为屏幕宽度减40px；左右固定20px。区块间距24px，内部间距以8、16、24、32px为主。

## 字体和尺寸

| 元素 | 规范 |
| --- | --- |
| 首页标题 | 30px，中等字重，42px行高 |
| 题干 | 20px，中等字重，30px行高 |
| 正文 | 16px，常规字重，24px行高 |
| 操作文字 | 16px，中等字重，24px行高 |
| 辅助信息 | 14px，常规字重，24px行高 |
| 主按钮 | 内容宽×52px，圆角14px，底部2px轻阴影 |
| 答案选项 | 内容宽×56px，圆角12px，间距8px |
| 长选项 | 同题所有选项统一增高；示例两行80px，不截断 |
| 进度条 | 高8px，圆角4px |
| 图标 | 标准24px；倒计时图标20px，计时组固定80px |
| 点击区域 | 至少44×44px |
| 辅助插画 | 图片容器240×160px，透明PNG，保持比例 |
| 图片或视频题区域 | 内容宽×144px；无素材时整体移除 |

设计文件采用 Noto Sans SC 无衬线字体。原生实现时使用系统无衬线字体，iOS优先PingFang SC，安卓使用系统中文字体；需重新核对换行。

## 状态与交互

V3/Button包含Default、Disabled、Secondary。V3/Option包含Default、Selected、Correct、Wrong。按钮和选项均为组件实例，文字可替换。

| 状态 | 表现 |
| --- | --- |
| 未选择 | 白底普通边框；“提交答案”禁用 |
| 已选择 | 杏橙浅底、清晰描边、勾选标识；提交可用 |
| 提交校验中 | 实现阶段禁用重复提交；等待服务返回后显示结果 |
| 正确 | 柔和绿色、勾选图标、“回答正确”、解析、下一题 |
| 错误 | 柔和红色、叉号、“再想一想”、解析、剩余次数与继续入口 |

“分享并继续学习”是复活入口的视觉文案。资格、次数、每日锁定以及最终判题继续由现有服务规则负责，Figma演示不执行这些逻辑。

答题页顶部进度固定，题干、媒体、选项及长解析可滚动；底部操作固定并保留安全区域。题目切换与页面状态转换建议160ms淡入，不使用闪烁、弹跳或爆炸效果。Figma状态导航已使用轻微淡入。

首页仅保留标题、短说明、书屋插画、示例进度、开始闯关、积分和排行榜入口。没有额外主题卡片墙或底部导航。本轮只有首页、答题页及其状态和适配画板。
