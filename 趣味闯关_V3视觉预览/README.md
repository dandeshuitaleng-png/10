# 趣味闯关 V3 · 两页视觉预览

暖白＋低饱和杏橙，采用现代简约答题小游戏的排版与反馈方式。首页以独立书屋插画辅助文化表达，答题页以题目、答案和底部操作为中心。

页面名称：V3 · 杏橙答题小游戏预览。文字、按钮、选项、图标、进度条均可编辑；插画为独立透明 PNG。两套组件为 V3/Button、V3/Option，颜色和间距通过变量关联，字号通过共享文字样式关联。

在 Figma 演示中，从375px首页“开始闯关”进入答题默认页，点击 B 选项进入选中预览，再点击“提交答案”查看正确状态。错误状态可直接打开对应画板。这些连接只演示视觉状态，不校验答案或执行实际分享。

## 检查结果与范围

已逐张查看全部15张页面导出，检查375、320、430px内容宽度与间距。主要按钮均为52px高、14px圆角；答题选项间距8px，普通选项56px高，两行选项统一80px高。

375px答题各状态的主按钮保持在 y=700—752px，320px为 y=628—680px；底部预留34px安全区域。首页主按钮完整可见。顶部预留44px状态区和44px微信导航区，原生区域为尺寸示意。

媒体题在375px需要滚动40px，长题在320px需要滚动70px。已提供滚动前后独立预览；末项可完整显示，底部操作保持固定。无素材的题目不保留媒体区域。当前解析示例为单行。实现时，超长解析放入内容滚动区，避免挤占底部按钮；其真实设备表现待实现后检查。

正确状态使用勾选图标、提示和解析；错误状态使用叉号、温和提示和继续学习入口。绿色文字已调整为 #34734F，主要正文、辅助文字和状态文字的对比度均超过4.5:1，详见QA记录。

当前交付为视觉预览及Figma状态演示。题目、进度、时间和积分相关文字为示例；视频只有封面与播放控件示意，尚未播放真实视频。没有改动现有题库、服务、积分或复活规则。记录的60个小程序源文件校验值均未变化。微信真机表现和接口交互将在视觉确认、开始实现后验证。
