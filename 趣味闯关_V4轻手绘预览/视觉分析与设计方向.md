# 趣味闯关：以旅行青蛙参考发展轻手绘视觉

本次美术分析以用户提供的四张参考图为依据。设计目标是温和、有生活感的二维手绘知识小游戏；界面仍以375×812px为基准，只制作首页和答题页及其状态。原项目基准为demo v0.3.0，本轮不修改业务实现。

## 风格的运作方式

### 线条与造型
轮廓偏灰绿、灰褐，线宽有细微变化，物件边缘略有起伏。建筑、植物和器具被概括成易辨认的形体：窗框只需几笔，植物用一组明确的叶形。参考画面主要通过轮廓和色面表达，而非写实材质与精确光照。这种人为取舍比随机笔刷纹理更重要。

### 色彩与明暗
参考里有较明亮的角色绿，但环境多为米黄、灰绿、木褐。颜色按主体与环境分配，不平均争夺注意力。单个物体保留一层浅阴影即可，不增加高光、泛光和复杂体积渐变。

本项目沿用0.3的米白#FFFCF0、蓝绿#176B80、橙色#E89246、草灰绿#607664、浅绿#DCE9DF、墨绿#263D34。蓝绿用于主操作；米白承载内容；橙色用于进度等小面积强调；草灰绿用于线条和环境。既有米褐#EFEAD9可做辅助底色。

### 构图与空间
参考中的空间有前景围合、中景活动和背景建筑，但透视与比例服从构图。大叶片常在边缘，中间地面较安静。层次通过遮挡和大小建立，保留真实可识别的生活场所，不依靠散落符号或抽象色块。

### 细节与情绪
器物有清楚的使用关系：椅子可以坐，杯子放在桌上，信箱在门旁。小动作、生活物件和安静的场景传达轻松感。本项目用竹椅、阅读桌、图书和乡村书屋表达这种日常关系，画面内容重新围绕湖南乡村阅读设计。

## 转成产品界面的规则

| 部位 | 设计规则 |
| --- | --- |
| 首页 | 清楚的标题、局部书屋小院插画、示例学习进度、唯一强主按钮；保留积分与排行榜入口 |
| 背景 | 干净米白底，场景仅占页面局部；文字区域保持平整 |
| 主按钮 | 蓝绿实色，浅色文字，统一52px高，圆角14px，轻微底部按压厚度 |
| 次要入口 | 轻图标与文字组成，不再放进重边框的大面板 |
| 答题 | 系统无衬线20px题干；四个整齐选项；顶端进度和固定宽计时；底部操作固定 |
| 手绘感 | 放在插画、图标和少量边线中；文字、选项对齐与点击区域保持精确 |
| 反馈 | 图标＋文字＋色彩共同表达；正确显示解析，错误保留分享复活与返回入口 |
| 四主题后续 | 共用线条、比例、色彩分工与布局，主题内容再变化；本轮不提前制作主题页 |

## 美术检查条件

- 同一张图的轮廓粗细、物件比例与阴影方向一致。
- 细节必须在手机实际尺寸中有作用；缩小后成为噪点的细节删除。
- 插画不能带泛光、塑料高光、厚重水墨或写实材质。
- 不把书本托底、纹章、散落星光当作构图捷径。
- 按钮和文字不能由整页生成图承载；最终Figma文字、进度、按钮和图标可编辑。
- 配色、尺寸与视觉演示通过，不等于微信真机、服务端和正式业务验收通过。

参考：用户提供的四张视觉图。产品信息另核对[Hit-Point官方页面](https://www.hit-point.co.jp/games/tabikaeru/)；上述视觉规则是本次对参考图的观察与设计推导。
