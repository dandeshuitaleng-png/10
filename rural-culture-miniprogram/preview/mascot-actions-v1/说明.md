# 智小谷 · 动作扩展 V1

以客户提供的「智小谷-阅读同行」平面形象为原型，制作六种动作候选。保留蓝白脸型、金色穗饰、圆眼镜、天线、黄外套与蓝领巾。

| 动作 | 建议使用场景 |
| --- | --- |
| 挥手迎接 | 首页、首次进入、活动欢迎 |
| 伸手指路 | 探索路线、当前关卡引导 |
| 托腮思考 | 答题提示、等待思考 |
| 跃起欢呼 | 回答正确、单关完成 |
| 展示成就 | 主题完成、学习成就 |
| 抱书休息 | 当日学习完成、明日再来 |

本组为 AI 生成的透明 PNG 动作源图，不是可编辑矢量文件；现已通过 256×256 衍生素材接入本地四主题小程序。客户原始素材、小程序品牌图标、现有运行页面和工程包均保留。动作语义不表示实际玩家进度，接入时应由真实业务状态决定使用时机。

建议一个区域只保留一个主角色。场景道具围绕动作增加，避免同时堆放书本、奖杯、灯泡和装饰。路线页采用指路动作；答题页采用思考动作；结果页分别采用欢呼或成就动作；当日结束采用休息动作。

生成方式、完整提示词与原型路径见「生成记录.json」。预览页可查看大图、浅深背景和 64px 显示效果。
