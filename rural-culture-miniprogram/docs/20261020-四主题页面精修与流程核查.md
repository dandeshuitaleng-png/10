# 四主题页面精修与流程核查

本轮完成约定的第 1、2 项：四主题逐页精修，以及答题、复活、通关、解锁和学习记录的流程核查。继续采用现有的一套卡通插画、主题色和原始二维智小谷素材。

## 已修正的问题

| 问题 | 修正后的表现 |
| --- | --- |
| 首页标题区使用固定高度，生态水纹超出边界 | 根据四套素材的真实可见边界计算标题区高度；标题字形、位置和横幅图片保持原样 |
| 两行题干时，第四个选项被底部裁切 | 收紧卡片间距，将底部留白放到答题内容容器内；当前微信开发者工具视口下四个选项完整显示，题干字体和选项高度保留 |
| 窄屏主按钮文字偏挤，部分小按钮点击区域偏小 | 窄屏首页主按钮使用 17px 字号；积分入口与证书切换按钮保留至少 44px 点击区域 |
| 长积分条目、昵称或证书名称挤压相邻内容 | 文字允许正常换行，积分数值不被挤压，长昵称和证书标题保持在卡片内 |
| 页面存在“本游戏”“全部启用关卡”等不统一表述 | 统一为主题学习证书、全部关卡、本关学习已完成等用户可理解的文案 |
| 联网续答时丢失刚选中但尚未提交的选项 | 仅在继续同一挑战、同一道题时恢复选中项；换题、重新闯关或挑战改变时清空，倒计时仍由原期限决定 |
| 旧地图和首页测试夹具无法加载现有页面依赖 | 接入真实展示模块，保留服务替身，恢复地图提示、标题边界、滚动定位等断言；标题避让工具读取当前实际横幅 |

角色继续按场景使用阅读、钻研、爱心鼓励、锦鲤休息、鼓舞庆祝和滑板比耶等原稿。当前与已到达节点保留角色，未来未解锁节点隐藏角色；关卡造型继续按目录顺序循环。

本轮没有重画素材、修改主题色、增加 B 方案、限制业务关卡数量或改变积分规则。后台地址、身份配置、题库目录、真实学习记录及数据库结构保持原样。

## 页面与状态核查

四主题逐一检查了 14 个页面或状态，共 56 项：首页、闯关须知、默认答题、答对解析、答错复活、复活分享、今日锁定、结果、我的学习、积分、空榜单、有数据榜单、证书未获得和已获得。

额外检查了两行题干、长积分条目、长昵称、长证书名称和证书切换区域。核查采用微信开发者工具的隔离评审工程，当前截图为同一视口；长文字检查仅注入展示数据，不修改真实题库或学习记录。

完整截图位于 `qa/four-theme-finish-20261020/after/`，答题页间距修正后的补充截图位于 `quiz-refit/`；长内容截图与尺寸记录位于 `content-fit/`。入口的可视化核查清单为同目录 `index.html`。

## 流程与验证结果

- 115 项自动回归通过：服务 39 项、实际 Page 32 项、四主题联网 Page 4 项、原生 HTTP 服务集成 8 项、地图与首页布局 12 项、内容和动作 20 项。
- 四主题按每关 10 题执行页面逻辑，检查取消分享不扣次数、复活后继续原题、退出后续答、首次计分、重温不重复计分、逐关解锁、次日解除锁定、排行榜及证书持久化。
- 隔离 HTTP/SQLite 测试完成四主题 16 关、160 道题，验证累计 300 积分和 5 张证书记录；测试完成后临时服务和数据均销毁，没有向正在使用的账号写入作答。
- 32 组实际横幅像素与微信胶囊避让计算通过；这是计算验证，不代表对应尺寸的真机验证。
- 母工程、四套独立工程和平台总入口的原生 WXML/WXSS 编译全部通过，最大主包 2,001,366 字节，小于 2MiB。
- 原有插画、标题与角色资源哈希保持不变；五个运行文件同步至六套工程，连接与身份配置保持不变。

分享取消与复活分支使用受控服务验证，未将其等同于真实微信分享成功确认。第 3 项中的微信真机及完整设备适配验收不包含在本轮完成范围内。

## 复核入口

在 `rural-culture-miniprogram` 目录运行 `npm run test:finish`，可复现自动回归、标题避让计算和六套工程编译。

原生截图核查使用 `tools/check-four-theme-finish-native-20261020.cjs`；长内容核查使用 `tools/check-finish-content-fit-20261020.cjs`，均只连接 `.rural-quiz-runtime/theme-content-review` 隔离工程。

逐项结果和日志见 `qa/four-theme-finish-20261020/regression.json`、`verification.json`、`change-audit.json`，以及各项测试日志。
