# 声音设置面板

入口放在页面左上角，沿用原小喇叭的位置，改为一个小齿轮；点击区域 44×44px，避开标题和微信胶囊。主页和内页共用同一个入口，没有另加设置卡或主题入口。

点击后，从底部展开对应主题的浅色纸面板：红、棕、金、绿分别沿用现有色板。面板内提供两组控制：

- 背景音乐：独立开关、0–100% 音量，默认 40%。
- 互动音效：独立开关、0–100% 音量，默认 60%。拖动结束后播放一次木质音，便于确认音量。
- 底部提供“全部静音／恢复声音”和“完成”；点击遮罩或右上角关闭也可收起。

普通开关关闭时保留原来的音量；全部静音后恢复原先启用的声道和音量。滑动过程实时改变音量，松手与收起时保存。关闭页面、再次进入后继续沿用；兼容旧版关闭全部声音的选择。

默认混音保持上一版自然声音的实际音量：主页钢琴 0.12，答题 0.07。百分比表示应用内部的相对音量，最高值受该声道混音范围控制。视频题避让、后台暂停、首次手势后播放和自然材质音效继续保留。

面板打开时暂停非必要人物动作；答题计时照常进行，并在答题中显示提醒。答题超时等业务弹窗出现时自动收起设置面板。未添加重置学习进度、调节动态效果、返回总入口等功能。
