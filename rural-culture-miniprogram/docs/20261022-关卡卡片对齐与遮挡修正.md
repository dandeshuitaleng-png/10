# A 方案关卡卡片对齐与遮挡修正

按最新要求，仅用水平对齐建立卡片与关卡的对应关系，不增加短线或其他连接装饰。四主题沿用甲方已确认的 A 方案、原图、横幅和四季智小谷。

## 原因与修改

实际浏览器复现中，后加载的旧反馈样式把说明卡抬高，卡片中心比对应底座中心高约 46.24px；锁标记位于底座下方，侵入下一张卡片。单独下移卡片后，较窄屏幕上已经到达的相邻人物仍可能与卡片相交，原回归缺少此情况。

- 卡片中心对齐可见底座图片的中心，保持 10px 横向间距；不加连接线。
- 锁定、完成和今日锁定标记收回各自底座的右下角，不再悬在相邻卡片上方。
- 在原 S 形路径范围内微调章节纵向位置，按屏幕宽度为每个四季人物预留空间。解锁和完成状态变化不移动关卡；原底图保持 750×1280 比例。
- 首页定位使用卡片和底座的实际下边界，当前卡片与人物完整可见。说明卡、人物、底座仍由同一个关卡容器带动滚动。

实现集中在 `services-v4/home-layout.js`、`services-v4/journey.js` 和 `pages/game/approved-a-20261021.wxss`。母工程与四套独立工程保持相同修改；关卡 ID、目录顺序、判题、进度、积分、音频和获证规则均沿用既有实现。
