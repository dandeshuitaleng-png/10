# 趣味闯关：按当前合同核对本地待完善事项

核对日期：2026-10-18。依据是用户本次提供的《微信小游戏“趣味闯关”系列开发合同(1).docm》，不是以前另一份1012版合同。以下为功能与实现核对，不是法律意见。

已确认：甲方尚未提供平台登录/同步接口、PC接入方式、服务器与DM8/TongRDS测试环境。本地能完成的部分先推进；不把这些外部资料作为本地功能可以停做的理由。用户明确取消题库审核，不再把题库审核列为待交付功能。

## 结论

现有资产已经包含四主题视觉、16关本地玩法、管理页面，以及具有持久化和动态配置能力的独立后端。但新版原生小程序、Vue管理页面和后端仍是三套未接通的数据链，完整系列尚不能按合同验收。最先完善数据链，随后补跨主题总证书和真实用户数据，再完善媒体、PC和异常场景。

合同约定“系列游戏包含四主题、每主题四关、支持小程序及PC参与”，没有指定必须四个独立AppID。交付目标按完整系列系统理解：四主题共用用户、规则、积分和证书服务，能汇总16关。当前四套独立工程可继续保留为源码/构建产物，不能让工程拆分阻断总证书和跨入口恢复。不在本次检查中擅自合并或重做已确认的四主题UI。

## 本轮已经完成：取消题库审核

- Vue管理首页的待审核统计、审核筛选、表格列、表单项、详情项及CSV审核列已移除；旧CSV与旧浏览器存档可读取，旧审核字段不再要求或继续保存。
- 服务端取消审核判题池条件与review操作接口。新增/编辑/导入合法题目按启用状态直接可用；已明确停用和删除的题目不会因为迁移自动恢复。
- 原有240题从待审核迁为可用，题号、题干、选项、答案、解析、版本和素材保持；玩家通关、账本、证书和同步记录与迁移前私有SQLite备份一致。
- 原生四套服务不再输出“题库待审核”标识。界面仍保留本地体验/正式运行的区别，不把测试分享或本地数据冒充甲方平台成果。
- 题库结构、四选项、正确答案、重复编号、关卡归属等校验保留。玩家API仍不返回未作答标准答案；没有把240题作者答案打包进旧联网玩家bundle。

这项不包含“把新版小程序接入后端”；P0-1仍需继续实现。

## 暂等甲方资料的事项

1. 平台用户授权登录与数据回传：缺接口、字段和测试账号。本地可先做可替换的身份/同步适配与模拟接收端；不能标为已与甲方打通。
2. DM8与TongRDS：现有存储为SQLite；store注入点只是扩展接口，尚无实际DM8驱动与TongRDS实现。可先完成接口层、迁移脚本、连接配置、超时/重试与适配测试；指定环境的事务/过期/故障验收等待真实环境。
3. 国产系统/浏览器/终端、微信手机和PC客户端：可先准备测试矩阵与资源规范；实际兼容性与真机验收要有指定环境。
4. 正式HTTPS域名、资源域名、AppID归属、跨小程序跳转和发布：现有总入口的四个目标AppID仍为空，不能把本地preview跳转当成原生正式入口已完成。已有工程填AppID不等于平台配置、审核或发布通过。
5. 线上培训、交付签收及1年质保起算：本地代码/压缩包不能代替实际培训、书面验收与售后流程。
