# 答题布局与按钮交互修正（2026-10-21）

用户反馈：手机微信中，iPhone 与安卓的答题选项在点击后有间距、越界或遮挡问题；连续点击一段时间后，按钮的弹动反馈消失。修正同步到母工程和四个独立主题。标题、插画、主题色、题库、积分、计时和服务接口保持既有配置。

## 修正

1. 取消“读取按钮高度 → 向上取整 → 写回所有按钮高度”的循环。选项现在由原生 flex 布局按自己的文字自然换行，最小高度为 56px。长选项不再把其他短选项一起撑高，也没有上一题的异步测量值影响下一题的入口。
2. 明确答题滚动容器、选项容器和按钮的 border-box 与宽度约束。选中的加重描边在按钮内部绘制；按下时轻微向内缩放，避免放大或位移越出答题区。长内容在固定提交按钮上方滚动，底部保留 16px 间距。
3. 增加独立触摸反馈控制器。反馈状态不依赖“是否已选中”，刷新答案也不会清除按压状态。短点击至少保留 100ms 反馈，释放后还原；新触摸接管旧计时器，避免旧回调清除后一次按压。
4. 滑动超过 8px、触摸取消、页面切换或进入后台时清除按压状态；卸载时释放计时器。系统要求减少动态效果时保留明暗／内描边反馈并关闭缩放。
5. 同步用于选项、提交／下一题、弹窗主按钮、关卡按钮、顶部快捷入口、小图标和声音设置按钮。智小谷沿用已有独立人物交互；原生开关和滑块沿用原生反馈。禁用和加载状态不触发有效业务动作。

## 复现与验证

旧声音设置交付包里的真实 Page 源码，用相同实际服务和可控小数像素回调运行，两个回归均失败：连续选择使高度累加；旧题回调把新题改成 148px。记录在 `qa/interaction-20261021/baseline-failing-regression.log`。新代码通过相同两项回归。

自动回归共 56 项：实际 Page 和服务 34 项、布局／触摸控制器／共享组件 7 项、声音 11 项、四主题联网 Page 4 项。涵盖连续点击、相同选项再次点击、旧计时器、滑动取消、后台清理、禁用／加载，以及既有答题、复活、证书、声音设置与媒体题流程。

原生渲染记录见 `qa/interaction-20261021/native-checks.json`，包含 WXML 触摸绑定、共享组件和四主题 × 320×568／375×812／430×932 的连续选择、长文字、按压边界与末项滚动检查。尺寸为隔离评审工程的容器及窗口参数，宿主模拟器仍是 390×844，不是切换实体手机型号。截图只用于本轮布局验证。

母工程和四套独立工程运行原生 WXML/WXSS 编译及资源体积检查，结果见 `qa/interaction-20261021/compile.json`。整份交付 ZIP 大小与各主题实际主包大小分别记录。

本轮未连接实体 iPhone 或安卓，不能代替手机微信复测；未生成新的扫码预览、上传或发布版本。源码式浏览器预览同步了指针事件桥接，本轮没有浏览器自动化验收。
