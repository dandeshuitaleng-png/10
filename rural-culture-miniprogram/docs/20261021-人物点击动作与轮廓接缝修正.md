# 人物点击动作与轮廓接缝修正

本轮针对“点击人物设置动态”以及用户四张截图中的断线、重影问题，统一处理四季智小谷。保留 A 方案布局、原人物 PNG、主题配色及既有业务数据。

## 动作

- 春：空着的手抬起招呼，身体、脚底和风车保持稳定。
- 夏：手与冰淇淋一起轻抬，游泳圈与脚部保持稳定。
- 秋：持相机的手轻抬，配合镜头回应，头部与脚部保持稳定。
- 冬：手与糖葫芦一起轻摆，雪人与脚部保持稳定。

点击动作持续 1.35–1.5 秒，先快速回应，再自然收回。连续点击会更新短促的互动提示，不重新切断正在播放的手部动作。日常待机、点击、页面刷新、后台暂停和系统减少动态设置沿用同一控制器。

## 轮廓修正

移除了会暴露透明缺口的手臂裁切、多层补色和分片 CSS 变换。静止时直接显示完整原 PNG；动作时由一个 Canvas 2D 连续绘制局部原像素网格，所有相邻单元共享同一帧和同一组顶点。局部区域的外边界固定，其他部位继续绘制原图，避免断线、浮边、重叠和脚底漂移。

没有重新绘制人物。四张原 PNG 的 SHA-256 均与原素材记录一致。浏览器评审使用同一绘制模块，预览适配器仅提供 Canvas 与图片生命周期。

- `tests/mascot-motion.test.cjs`：每季连续 100 次点击不重启动作，点击反馈序号递增，完成时停止；保持最多两个控制器计时任务。
- `qa/home-designs-20261021/click-motion-component-regression.log` 和 `click-motion-page-regression.log`：28 项组件/动作检查与 34 项实际 Page 回归。
