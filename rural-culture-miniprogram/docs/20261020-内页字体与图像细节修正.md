# 内页字体、图像与间距修正

根据用户提供的四张截图，保留现有卡通画风、主题横幅和页面顺序，统一修正内页细节。

| 截图问题 | 本轮处理 |
| --- | --- |
| 生态横幅的水纹压到倒计时区域 | 为横幅和操作信息划出独立区域，内页内容从横幅下方开始；退出、关卡名与倒计时保持一行 |
| 题干粗宋体过重，换行不清楚 | 统一为系统中文无衬线，中等字重 600；常规 20/30px，小屏 19/29px；减小题角装饰，给正文保留空间 |
| 答题卡里的智小谷太大、贴边 | 从绝对贴底改为与文字并列的居中布局，375px 下角色 44×54px，位于白卡内部，原 IP 与动作不变 |
| 复活弹窗字体、角色和间距不统一 | 标题 20/28px、说明主句 16/24px、正文 14/24px、辅助文字 12/20px；角色 64×76px，统一上下间距；关闭按钮仍为 44×44px |
| 小屏内容与操作竞争空间 | 缩减多余留白，375px 常规短题保留完整四选项；长题自然滚动，提交按钮固定；隐藏干扰卡片右侧的原滚动条 |
| 禁用按钮文字太淡 | 组件内显式设置禁用文字颜色，仍保持不可提交状态 |

已同步母工程、四套独立工程与平台总入口，PC 和浏览器复用页读取同一套原生样式。四主题的实际微信模拟器答题和复活页面已逐一打开并查看，另核对生态长题及滚动后的选项。该检查使用隔离本地 mock 工程，题干取自用户截图和既有长题样例，选项明确标注排版样例；不作为正式题库答案。样例固定时间以便同状态截图，不用于证明倒计时行为。

实际原生计算样式核对：题干系统中文无衬线、字重 600，答题卡角色 44×54px。相关 Page 21 项与地图 3 项回归通过，六工程静态编译通过。原 IP、其他主题素材、业务接口和正式 HTTP 配置均未改变，测试不写入真实后端或学习记录。
