# 关卡人物随进度出现与动作完善

2026-10-19。根据用户最新澄清，人物按到达进度显示，四主题沿用同一套规则与视觉组件。

## 人物出现规则

- 未解锁关卡：只保留底座、序号、锁定标记与说明卡，不显示智小谷。
- 当前关卡：出现该关专属姿态并播放短动作。今日锁定仍属于已到达关卡，保留人物。
- 已完成关卡：保留原姿态和完成标记。继续下一关时，新关卡才新增人物。
- 人物映射按照服务提供的启用目录顺序循环，不把业务关卡总数固定为四关；停用、改序仍跟随目录。

四关默认顺序为：风车轻躬身招呼、相机探身观察、糖葫芦低头思考、游泳圈伸展庆祝。保留用户原始二维 PNG，在运行时以脚部为支点做不同的短姿态变化，配合不同的眼睛与道具动态；没有重新画人物，也不将其描述为新绘的挥手或四肢骨骼动画。

当前可见角色首次出现时播放一次，此后每 8 秒一次。已完成节点点击可播放；未解锁节点不会触发人物播放。全完成地图由最后一个可见的已完成人物播放动作。动作约 1 秒，思考约 1.2 秒。

## 内页与按钮

答题、答对反馈、学习成果、我的学习、积分、已获得证书页面，以及须知、复活和今日锁定弹窗，均复用动作组件。答题与须知的姿态跟随所到关卡；成果与证书采用庆祝动作。打开弹窗后暂停背后地图或内页的角色。页面进入后台、角色离开滚动可视区或开启减少动态效果后停止。

底部按钮继续使用 52px 圆润轮廓，增加书本小徽面、内嵌箭头环、轻高光与按压层次；快捷入口图标与节点状态标记使用对应主题的边框和浅底。题板、须知信息格、按钮与弹窗延续各主题的红、棕、金、绿配色。正确、错误与警示保留语义颜色和文字。

只为青山绿水使用专用生态横幅；其余三个原标题、地图图片、节点坐标和比例不变。后端、题库、积分、存档和业务 API 不变。当前继续只有一种方案。
