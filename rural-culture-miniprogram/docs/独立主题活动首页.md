# 独立主题活动首页

依据用户2026-10-16提供的层级反馈：一个主题就是一个独立活动，首页应直接呈现关卡、进度和奖励。

## 当前结构

1. 每套工程默认进入自己的活动首页，显示主题名称和主题介绍。
2. 首页顶部显示实际完成关卡数、进度条和当前用户在本主题获得的积分。
3. 四个启用关卡直接以地图节点呈现，不再经过“介绍首页→查看关卡”的中间步骤。每关显示名称、完成/解锁状态和首通奖励。
4. 已完成关卡的奖励读取历史积分账本，不用更新后的配置伪造历史领取值。重温不重复计分。
5. 主按钮直接开始当前关卡；有进行中的题目则继续原题序、选择与截止时间；今日锁定时查看锁定说明；全部完成时查看学习证书。
6. 排行榜、通关证书、我的学习保留为辅助入口。活动首页不设置返回另一个同主题首页的按钮。

## 页面与样式

首页使用完整页面，移除外层悬浮面板、四周暗色背景和大幅介绍图；恢复原有装饰题头，作为页内标题使用。`home`与兼容入口`levels`显示相同的活动首页；规则、复活等操作弹窗保留原行为。

四主题复用原有 header.png、场景、地图、角色动作及主按钮样式；千年文脉为卷轴、十步芳草为橙红缎带、金色产业为绿色缎带、青山绿水为原表情插画配描边标题。未采用本轮新生成的题头。进度面板、关卡说明牌与奖励标签增加高光、底座及投影，但外层保持完整页面。

四主题沿用各自场景与配色，首页当前节点使用智小谷指路动作；今日锁定使用休息动作。当前启用目录拥有节点数量、排序、名称和奖励，界面不新增或合并玩法。

常见尺寸可在同一首页浏览四关；短屏采用内容区滚动并定位当前关卡。三个非文化背景的最高弯采用y=0.24的锚点，配合80px关卡说明牌，避免小屏相邻奖励卡片碰撞。
