# 趣味闯关 UI 原型验证记录

日期：2026-10-13。范围：独立目录 `rural-culture-miniprogram`；既有demo、后台、题库和交付资料未修改。

## 已通过

- 20项服务检查：四主题/16章节/48题、初始空记录、禁止越过锁定章节、题目不下发标准答案、提交幂等、复活资格、重复复活不多扣次数、每日锁定与跨日重置、服务端超时判题、全部章节通关、300演示积分、四张主题证书及一张总证书、重复通关不重复奖励、排行、真实接口响应与网络失败反馈。
- 17项浏览器流程和布局检查：实际读取原生Page/Component、WXML/WXSS和services，完成：首页→主题→章节→答题→解析→结算→下一章节；动态三选项题目、取消模拟分享保持待复活、确认模拟分享调用服务、再次答错暂停、榜单切换、未获得证书空状态、加载失败重试、主题/总证书与图片导出、题目图片展示。
- 320、375、390、430、768、1280px六种宽度的首页、主题、章节、答题、学习足迹、排行和证书没有横向溢出。窄屏使用单列，宽屏主题两列。
- 本机微信编译器：11个WXML（8页+3组件）和12个WXSS（8页+3组件+全局）编译通过；JSON与JavaScript语法检查通过。
- 微信开发者工具原生模拟器：已打开独立测试号项目，核对首页、主题、章节、答题显示，主题卡片与章节条目可跳转；验证超时未通过反馈、模拟服务恢复资格后的正确反馈，以及自定义按钮继续下一题事件。原生章节结算也已显示。正向补题部分使用页面业务方法调用。
- Figma：统一颜色/间距/圆角变量、中文字体样式、共享按钮、九个页面/状态画板、20条点击连接。全部页面已渲染并查看；文字、矢量插画和组件可编辑，横向边界检查通过。
- 远端接入骨架包已检查排除 `mock-server/` 和本地答案，不能误把模拟答案带入正式前端包。

## 检查中修正

修正了原生微信默认按钮宽度、窄屏全宽插画边距、Figma横向自动布局的文字裁切、浏览器预览的多段表达式处理，以及答题完成状态再次进入时的结算跳转。原生答题反馈中的选项文字显式使用墨灰，避免微信禁用按钮默认浅灰影响阅读。
