**建议建立的组件规则（下一版候选，尚未实施）**

- 图标按用途分为辅助16px、常规20px、一级入口24px；外框与可见图形分开定义。触控区域继续独立保留44px或以上，不把小图标等同于小点击区。
- 使用同系列圆角线性图标；在24px基准下先比较约1.75–2px的笔画方案。这个数值是项目设计候选，不是腾讯或平台强制标准。
- 颜色定义为默认、辅助、强调、禁用和语义状态；四主题共享角色规则，并保留各自配色。
- 卡片分为静态信息卡、可进入的功能卡和答题选项卡，分别定义排版、圆角、边线与反馈。同角色共用样式；不同角色允许有受控差异。
- 浅渐变主按钮保持52px；次操作的高度、底色和字重更轻。选择、正确、锁定、禁用不能只靠颜色区分。
- 图标在1倍尺寸、完整页面和四主题并排三种场景中评审。24px框或中心坐标通过，仅是布局条件，不等于视觉质量已经通过。

**应保留**

四主题识别、原插画和原人物已经建立；三张首页入口的等宽等高与组合居中基本正确。答题选中状态有边框、底色和实心标记，文字标签也较清楚。保留这些成果，避免重新推倒版式。

**无障碍与证据边界**

截图能确认标签可读、部分点击区大小及选中状态的多重表达；不能证明读屏、键盘、全流程对比度或真机效果合格。须知打开时无障碍树仍报告背景开始按钮保持焦点，应进一步检查焦点移入和关闭后返回。隔离评审时钟固定，本轮不评估倒计时。未检查完整排行、证书生成、结算、错误与网络异常。
