# 四套独立前台的接入说明

> 历史/阶段记录：以下保存当时的规则、方案与验证范围。当前仅维护 A 方案，四套 HTTP 数据链已接通，题库不设审核模块；旧接口、旧报告及提交前状态不作为现状结论。当前实现和检查入口见 [当前工程状态](CURRENT_STATUS.md)。

原工程已接入可运行原生页面；四套分别构建。目录和题库只包含自身游戏，存储、挑战、账本、排行、证书以固定gameId隔离。综合入口与跨游戏总证书留在平台侧。

本轮不改 demo 的本地数据库，也不新增正式接口。原生旧 `services/remote.js` 的占位路由与 demo `/api/catalog`、`/api/me`、`/api/challenges`、`/api/rankings`、`/api/certificates` 不是同一合同，不能仅配置地址后宣布接通。正式接入需后端确认游戏级权限、目录范围、计时、幂等判题、复活资格、首通积分和榜单范围。

| 能力 | 当前本地原型 | 正式接入要求 |
| --- | --- | --- |
| 身份 | 本设备本地记录 | 平台签名身份与用户昵称授权 |
| 判题与时间 | 独立services模拟引擎、绝对期限 | 服务端时钟、无答案DTO、幂等请求 |
| 复活 | 明确点击模拟结果，取消不计次 | 后端核验，分享返回不等于资格通过 |
| 数据隔离 | 固定gameId目录及命名空间 | 后端按游戏授权，不过滤跨游戏结果冒充隔离 |
| 积分与排行 | 本游戏演示记录，示例昵称明确标识 | 服务端账本、日界线、排序规则 |
| 证书 | 本游戏本地模拟证书 | 后端签发、历史范围、平台总证书汇总 |
| 图片/视频 | 原生媒体容器，演示场景图 | 合法素材、真实URL、合法域名、加载失败处理 |
| 保存/分享 | 原生canvas、相册及分享入口 | 真机权限与真实平台验证 |

V5四套当前有效主包约0.42–0.49MiB，原始插画保存在独立设计交付中。微信实际上传、审核及正式AppID状态另行验收。
