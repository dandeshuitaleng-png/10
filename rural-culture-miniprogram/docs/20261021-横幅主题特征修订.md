# 横幅主题特征修订

本轮修正红色、文脉横幅只有颜色差异的问题，在统一折叠缎带形制上增加主题识别。十步芳草用红旗与纪念建筑表达红色文化；千年文脉用书卷、竹简和书院屋檐表达历史与阅读。装饰放在两侧及缎带后方，中央保持实际文字区域。金色产业麦穗、青山绿水山水保持原素材。

新源图及完整提示词见 [设计源记录](../design-source/title-ribbons-themed-20261021/README.md)。运行图分别约 62／82KiB。上一轮 v2 横幅保留在源代码中，包体排除旧版与其他主题新版。

本轮更新 `visual-feedback` 的横幅选择、`home-layout` 书写区、48 段上轮廓及分享封面位置；A、B、current 与内页共同读取。正式默认 current、四主题独立入口、人物局部动作及所有业务规则不变。

核查记录位于 `qa/home-designs-20261021/`：

- `themed-title-silhouette.json`：四主题、四档宽度与两种胶囊横向位置，32 项源 alpha 避让检查。
- `native-checks.json`：四主题 A／B 在三档约束容器中的实际微信渲染布局与导航，实体手机另验。
- `shared-ribbon-checks.json`：红色／文脉实际答题与须知弹窗的资源、文字框和截图。
- `compile-summary.json`：母工程与四独立工程编译、有效包体。
- `b-regression-summary.json`：按时间追加本轮首页、文字位置和分享封面回归，原有动作检查继续保留。

浏览器侧只核对交付源码及图片，未声称浏览器交互或手机微信验收完成。main 与基线标签不移动，修改前版本可回到提交 `72621d4`。
