## 动作内容与边界

保留全部原始 PNG 像素和人物外形，不重新绘制角色。运行时通过 CSS 区域窗口复用原图眼睛像素，并用取自原图的纯蓝面罩颜色遮住静态眼睛底图；区域边界全部为原图同色像素，未盖到人物轮廓。身体、脚部、头身比例和道具形状固定。

- 风车：笑眼轻眯两次，风车局部微光。
- 相机：视线向相机轻移、眨眼、镜头短闪。
- 糖葫芦：视线下移、眨眼、糖葫芦微光。
- 游泳圈：俏皮眨眼、泳镜光泽变化。

动作约 1 秒，糖葫芦约 1.2 秒。当前可见节点首次出现时播放，此后每隔 8 秒播放一次；其他节点静态展示，点击未解锁节点时可播放一次。打开须知、复活或锁定弹窗后，动画转交给弹窗中可见的角色，背后地图停止。

页面隐藏、角色离开可视区域、开启“减少动态效果”或系统减少动态效果时停止。非角色弹窗也暂停地图动作。没有为动画延迟业务导航或改动题目计时。关卡数量仍由服务配置决定，不限制为四关。

本轮实现的是原图五官与道具局部动作，不包含新绘的挥手、转头、手臂或骨骼动画。个人页等未接入动作的插图仍使用原始静态图片；不把整张图片晃动当作局部动作。
