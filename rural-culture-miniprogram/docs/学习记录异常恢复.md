# 学习记录异常恢复

## 当前行为

- 学习记录写入失败：在内容区显示说明和“重试保存”，提示不会覆盖底部主操作，按钮保留至少44px点击高度。
- 重试仍失败：继续保留旧存档和当前内存进度，显示简短失败反馈。
- 重试成功：保存当前题序、选择和截止时间，清除异常提示；不会重开挑战或重新计分。
- 存档格式损坏：显示已保留原记录，不提供会覆盖原数据的重试操作。
- 浏览器原生预览读取损坏JSON时，将异常交给服务层处理，不再把损坏数据当作空存档。

正常游玩时不显示异常提醒。母版和四套独立主题工程已同步；没有修改后台数据、玩家真实存档、业务规则或正式服务配置。
