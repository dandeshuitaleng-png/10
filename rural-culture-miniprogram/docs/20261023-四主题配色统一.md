# 四主题配色统一 · 2026-10-23

> 阶段记录：本文保留 2026-10-22／23 的设计决策与当时检查结果。当前规则见 [维护索引](MAINTENANCE.md)，代码质量和远端检查见 [本轮修复记录](20261025-代码质量修复与验证.md)。文中的 qa/ 路径为本地历史存档，未随仓库全部上传，不能当作本轮重新验收。

本轮对应反馈：景物放大后的局部底色不一致，且顶部、卡片和按钮与地图的调性不统一。

已撤回局部放大合成。主源码与四套独立微信工程现使用此前接受的四张原地图，逐字节一致。画风、色彩、道路和构图保留。景物放大、顶部元素强化仍待后续在此基线上精修，本轮不将这两项记为完成。

UI 继续使用原有布局、图标、字体、卡片尺寸与人物站位，只统一色彩：

| 主题     | 调性   | 页面底色 | 卡片纸色 | 按钮渐变          |
| -------- | ------ | -------- | -------- | ----------------- |
| 十步芳草 | 暖朱红 | #FCF0EA  | #FFFAF7  | #F5DFD6 → #F0D4CA |
| 千年文脉 | 木棕   | #FBF2E2  | #FFFAF2  | #F3E3CD → #EDDAC0 |
| 金色产业 | 麦金   | #FCF6E3  | #FFFCF3  | #F7E9BA → #F0DDA6 |
| 青山绿水 | 草木绿 | #F2F7EB  | #F9FCF4  | #E5EED9 → #DCE8CF |

页眉与底栏使用同一页面底色，进度和功能卡使用同一纸色；地图卡片、滑动提示、内页及弹窗从同一主题配色取值。主按钮保留浅渐变。正确、通关等状态仍保留既有语义色。

`services-v4/visual-feedback.js` 为颜色来源；`tools/build-theme-tone-20261023.cjs` 生成页面和按钮的颜色样式。样式不包含尺寸、位置或文字层级的更改。目录、题库、接口配置和人物动画组件未改动。

验证记录见 `qa/theme-tone-20261023/`：四套 WXML/WXSS 与 JS/JSON 检查通过，均低于 2 MiB；8 项现有回归检查和 35 项页面检查通过；隔离浏览器检查四主题 × 五个场景的实际颜色覆盖、文字对比度和原地图一致性；四套独立微信模拟器已截图核对。

四个微信窗口恢复为内存中的全部通关评审状态（4/4、75 积分），用于对照画面。未改写远程学习进度，重新编译会恢复正常服务进度。本轮未上传、发布或进行实体手机验收。
