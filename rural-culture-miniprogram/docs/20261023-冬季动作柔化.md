# 冬季动作柔化 · 2026-10-23

> 阶段记录：本文保留 2026-10-22／23 的设计决策与当时检查结果。当前规则见 [维护索引](MAINTENANCE.md)，代码质量和远端检查见 [本轮修复记录](20261025-代码质量修复与验证.md)。文中的 qa/ 路径为本地历史存档，未随仓库全部上传，不能当作本轮重新验收。

针对上一轮冬季动作“有点僵硬”的反馈，保留可见的抬手幅度，调整动作衔接。上一版 16 帧与分段缓出叠加，存在抬起后固定停留、换方向时速度突变的问题。

现在冬季自动动作使用 32 帧、2000ms，点击回应使用 32 帧、1500ms。起手和结束的速度从零自然变化，关键姿态之间采用连续速度插值；原来的硬停顿改为很轻的持续变化，回摆幅度从 7° 收至 2.2°，随后逐渐停稳。没有增加自动播放频率。

冬季精灵单帧为 128×210px，16 列、4 行，包含自动动作和点击回应两组共 64 帧，整图 2048×840px，保持在 4096px 纹理范围内。四套仍使用常驻的同一张普通图片，通过 transform 逐帧播放；不增加运行时 Canvas，不切换整个身体可见性。

脚底、旁边的小雪人、原人物画风、地图、卡片和统一知识达人证书保持。其他九种人物配置不变，其他三个季节的原动作曲线和精灵图不变。共享插值器的原分支继续保留，只对冬季配置启用柔化曲线。

本次运行文件为 `services-v4/mascot-rig.js`、`services-v4/mascot-canvas.js`、`components/mascot-actor/index.wxss` 与 `assets/brand/map-motion/think.png`，母工程、四套独立微信工程及评审目录同步。

验证记录位于 `qa/winter-soft-motion-20261023/`：30 项动作与连续性检查，包含速度连续、轻微停留变化、无过大回摆、双组精灵起止帧和脚底/雪人固定；72 组浏览器帧和重复播放状态检查，包含减少动态效果；四套微信实际冬季组件、动作属性、包内资源长度和截图；五工程编译与主包检查；交付 ZIP 逐文件回读。

`冬季动作柔化-浏览器对比.gif` 是实际源码预览的逐帧对比，展示上一版与本版的动作衔接，不代表微信原生连续录屏。微信窗口保留全部通关的内存评审数据，方便直接观察第 4 关；没有作实体手机连续播放或发布验收。
