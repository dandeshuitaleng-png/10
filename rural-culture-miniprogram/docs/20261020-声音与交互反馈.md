# 四主题声音与交互反馈（2026-10-20）

四套主题均已接入同一套轻量声音：轻钢琴负责维持探索氛围，短音效只回应明确操作与答题结果。沿用现有画面、关卡与业务接口；四套工程分别进入各自主题，没有总入口。

## 已完成

- 删除“我的学习”中的“减少动态效果”整张设置卡及手动开关逻辑；系统减少动态效果偏好仍生效。
- 左上角增加小喇叭，视觉直径 32px、点击区域 44×44px，与主题配色一致，可一键关闭全部声音并记住选择。
- 默认允许声音，首次操作后才开始播放，进入页面时保持安静。
- 钢琴循环约 24.9 秒，渐入；主页音量 0.23，答题时降至 0.12。六类音效分别对应按钮、选项、答对、答错提示、人物点击和完成关卡。
- 答对、答错与完成音效以服务返回的确认状态触发；重复刷新不叠加，不在提交请求时提前播报结果。
- 视频题暂停背景音乐，下一道文字题恢复；进入后台暂停，返回前台续播，退出页面释放播放器。
- 浏览器预览桥接已加入音频接口，本轮未执行浏览器播放验证。

## 素材与处理

背景音乐为 Joth 的 [JRPG Piano](https://opengameart.org/content/jrpg-piano)；操作音效来自 Kenney 的 [Interface Sounds](https://kenney.nl/assets/interface-sounds)，完成提示来自 [Music Jingles](https://kenney.nl/assets/music-jingles)。三个来源页均标注 CC0。运行文件经过单声道 MP3 编码、频段与响度处理；音频共 212,151 字节。

原始选用文件、Kenney 许可说明与处理来源见 `design-source/audio-20261020/`；运行音频、逐文件来源与 SHA-256 见 `miniprogram/assets/audio/credits.json`。16 秒试听合成按运行音量混合，只用于素材试听，不是手机录音或游戏录屏。
