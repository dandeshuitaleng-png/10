# 首页阅读与滚动提示优化 · 2026-10-18

本轮落实已确认的两项：首页滚动可发现性和卡片小字可读性。标题、场景比例、关卡坐标、卡片外框、角色、按钮尺寸及主题材质保持。

## 显示规则

- 地图有溢出内容时，在本次页面打开后的第一次定位显示“上下滑动查看关卡”，约3.5秒后自动收起，实际滑动也收起。返回首页不重复显示，不增加存储字段或修改玩家存档。
- 地图上方还有内容时显示12px上边缘轻渐隐；下方还有内容时显示下边缘渐隐。到达对应边界即撤掉。无溢出、无关卡、错误或保存警告状态不显示提示层。提示和渐隐不占布局空间、不拦截点击与滑动。
- 状态文字11→12px，17px行高；奖励10→12px，16px行高；名称保持18px、24px行高。卡片仍为90px高，内部上下内边距各减少1px容纳字体增长，四行保持间距，不改变卡片中心或外部间距。奖励单行显示，异常长奖励文案以省略号处理。
