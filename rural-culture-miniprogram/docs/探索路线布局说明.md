# 活动首页关卡地图布局

最新首页层级以「独立主题活动首页.md」为准。每个主题为独立活动，首页直接显示动态关卡和奖励。

- 四套原生工程：同一份页面与地图映射，固定不同gameId、目录、素材和玩家存档。
- 页面铺满可用屏幕，系统状态区域使用浅底深色文字；标题左对齐，并为微信胶囊留出空间。
- 标题下是实际关卡进度、已得积分和三个辅助入口；底部显示证书奖励说明及直接开始/继续按钮。
- 地图背景为纯插画，文字、关卡编号、状态、奖励、指路IP和点击行为由原生组件呈现。
- 地图基础锚点为(0.67,0.85)、(0.30,0.64)、(0.67,0.42)、(0.26,0.17)；非culture主题最高节点按当前背景使用y=0.24。
- 原始背景及提示词在design-source/map-originals/和「地图背景生成说明.md」。
- 地图节点数量始终来自启用目录，扩展更多关卡会增加场景分段；短屏滚动并定位当前节点。

最新实际页面： http://127.0.0.1:6493/preview/v4.html ；四主题对照：preview/V8动作接入预览.html。
