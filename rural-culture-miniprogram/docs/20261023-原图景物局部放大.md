# 原插画景物局部放大 · 2026-10-23

> 阶段记录：本文保留 2026-10-22／23 的设计决策与当时检查结果。当前规则见 [维护索引](MAINTENANCE.md)，代码质量和远端检查见 [本轮修复记录](20261025-代码质量修复与验证.md)。文中的 qa/ 路径为本地历史存档，未随仓库全部上传，不能当作本轮重新验收。

本轮在配色统一的版本上补齐甲方要求的局部放大。采用本机 Vision 前景选区，只缩放原插画中的景物像素；没有重新生成插画，没有调色，没有移动道路或关卡布局，也没有新增运行时图层。

| 主题     | 调整                                                         |
| -------- | ------------------------------------------------------------ |
| 十步芳草 | 顶部原纪念物与红旗放大 15%；中右侧岩石、灌木和红叶树放大 18% |
| 千年文脉 | 顶部原书卷景物放大 12%；中右侧长椅与随附灌木放大 18%         |
| 金色产业 | 顶部原粮仓放大 20%；中右侧茶园与围栏放大 18%                 |
| 青山绿水 | 保留原地图                                                   |

顶部沿用原有纪念物、书卷和粮仓强化主题。山水远景与原构图保留，没有更换整片天空或重新绘制场景。

此前被指出有底色色块的矩形贴图合成已废弃。当前版本的透明选区不带整块底色；选区外、道路及其两侧 12px 保护带，在 JPEG 导出前逐像素不变。JPEG 导出存在正常的压缩差异。原文件与设计源文件保留，处理记录见 `qa/landmark-cutouts-20261023/`。

UI 继续使用上一轮统一的朱红、木棕、麦金和草木绿配色。人物组件、动画、字号、关卡卡片尺寸与站位、服务及题库配置保持不变，所有非地图文件均通过哈希保护核对。

本地验证：4 项既有地图布局检查通过；四套原生 WXML/WXSS 与 JS/JSON 编译通过，主包均小于 2 MiB；四套独立微信模拟器以 4/4、75 积分的内存评审状态截图检查，并对比前一版关卡与人物坐标。未上传、发布，也未进行实体手机验收。
