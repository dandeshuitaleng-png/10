# V2 · 新中式文化探索游戏

本次以2026-10-14的修订需求为准，替换上一版几何插画与网页式结构。定位为精品国风手绘场景中的轻量知识探索。

美术使用内置imagegen生成的五幅独立二维绘本场景，完整保留前景植物、中景建筑与远景山水。首页为乡村河桥全景；十步芳草为红色旧址院落与古树；千年文脉为书院、荷塘和书桌；产业振兴为稻田、农产与工坊；绿水青山为溪谷、森林与瀑布。旧址画面为概念场景，不冒充某一真实文物的精确复原。

首页标题在上，手绘主景占据视觉中心，下方为最明确的主按钮。主题选择使用独立场景的画卷入口，图文在不同空间分层。章节使用长卷场景与四个顺序书签节点，不使用复杂蛇形路径。答题采用宣纸书页，所有选项同宽、同内边距；计时、进度独立于装饰。结算以印章和学习记录呈现完成感。证书、排行、学习记录沿用同一墨绿、古铜和宣纸系统。

规范：手机边距20px，区块间距24px，面板内边距20px，正文17–18px，答题字号22px，主按钮至少54px高。标题用宋体、正文用系统无衬线。古铜色用于边框与纹饰，正文用墨灰；选中与正确状态用墨绿，错误用朱砂。四主题使用同一光影与绘本材质，区别来自文化景物而非换色。

本阶段保留上一版services与模拟业务规则。页面中的章节、题数和状态仍由配置与服务返回，插画不会承担判题或资格判断。完整原图保留于art-assets，发布使用独立JPEG资源，绝不用CSS几何图形替代美术。
