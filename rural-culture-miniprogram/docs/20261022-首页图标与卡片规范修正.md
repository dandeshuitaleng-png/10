# 四主题图标与卡片规范

> 阶段记录：本文保留 2026-10-22／23 的设计决策与当时检查结果。当前规则见 [维护索引](MAINTENANCE.md)，代码质量和远端检查见 [本轮修复记录](20261025-代码质量修复与验证.md)。文中的 qa/ 路径为本地历史存档，未随仓库全部上传，不能当作本轮重新验收。

2026-10-22 二次审查后的统一修订。保留已确认的 A 方案、四主题插画、横幅、原人物与关卡底座；修订共享的功能图标与界面组件。

| 角色         | 当前规范                                                                   |
| ------------ | -------------------------------------------------------------------------- |
| 首页入口图标 | 排行榜、证书、我的学习统一 24×24px，图文间距 6px                           |
| 常规图标     | 积分状态、声音设置、返回按钮、答题导语为 20×20px                           |
| 辅助方向图标 | 学习卡片与证书行的右箭头为 16×16px                                         |
| 图标家族     | 同一 24 单位网格、1.8 单位线宽、圆端点；深色 #5B5748，反白 #FFFFFF         |
| 状态容器     | 高 44px；进度与积分数字均为 18px／24px，字重 600                           |
| 首页入口卡片 | 三等分宽，高 44px，间距 8px，圆角 12px；图标与文字组成的整体居中           |
| 入口文字     | 13px／20px，字重 600，保持单行                                             |
| 学习入口卡片 | 两卡等宽等高，数字 24px／32px；标签与 16px 箭头组成居中入口提示，圆角 12px |
| 信息卡片     | 阅读者介绍、结算统计、总进度等信息面使用 16px 圆角                         |
| 主操作       | 52px 高、18px 文字；保留各主题浅色同色系渐变与细边线，无内高光和叠加阴影   |
| 次操作       | 至少 44px 高、15px 文字、字重 500，透明底与轻描边                          |

图标使用本机已有的 Lucide 1.8.0 原始路径，统一渲染为 72×72px 透明 PNG，不增加小程序运行依赖。共 22 种功能图标，原文件名及四个首页别名保持兼容。证书使用带印章的文档图形；学习内容使用打开的书；积分使用奖杯；背景音乐改为音符；互动音效改为声波。对勾继续只表达正确、完成与已选状态。首页主按钮移除重复的书本图形，保留右侧方向提示，文字相对整个按钮居中。

生成脚本：`tools/build-ui-icons-20261022.cjs`。来源清单、可编辑 SVG、原 PNG 备份及完整授权见 `design-source/ui-icons-20261022/`；小程序资源目录附 `LUCIDE-LICENSE.txt`。此前仅归一透明留白的方案已由这一套统一图形替代。

浏览器极窄长侧栏以手机预览框显示，宽度不超过 430px，高度不超过宽度的 2.8 倍。超出部分是预览框外的中性背景；游戏地图保持原始比例及底座、人物锚点，不拉长插画。该限制仅在浏览器适配器中生效，微信原生窗口测量逻辑不变。336×1291 四主题检查中，地图与底部按钮之间的内部空白均小于 10px；常见 320×568、390×844、430×932 保持原窗口尺寸。
