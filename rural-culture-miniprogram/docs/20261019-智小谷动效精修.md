# 智小谷动效精修

2026-10-19。本轮集中调整人物动效的质感，保持原 IP、主题界面与逐关出现规则。

## 动作设计

删除整张图片的斜切变形，将天线从原图中通过 UI 遮罩分离，围绕根部独立转动；眼神和道具使用各自的时间曲线。身体只保留不超过 1.5% 的竖向呼吸变化，脚部支点固定。

| 姿态 | 节奏 | 时长 |
|---|---|---|
| 风车·笑眼招呼 | 笑眼回应，天线轻摆后分次减幅回稳 | 1.8 秒 |
| 相机·观察定格 | 眼神先移向相机并停顿，再配合一次快门微光 | 2.1 秒 |
| 糖葫芦·凝神思考 | 视线下移，停留片刻，眨眼后恢复 | 2.3 秒 |
| 游泳圈·开心回应 | 轻快回应、泳镜掠光，天线回弹后柔和停稳 | 1.9 秒 |

四类动作都有准备、响应、停顿与回稳，速度和停留各不相同。道具微光按各自情境安排，不再共用同一个闪光时点。此处没有新增绘制的手臂、挥手或骨骼动画。

原始 PNG 文件的像素和字节未变；静态状态仍完整显示原图。天线、眼睛与道具窗口均复用原始图片，未重新画脸、穗叶、身体或配件。眼睛遮罩的八处边缘逐像素核对为原图蓝色，避免盖到嘴部或轮廓。天线原图层预先挂载，播放时仅切换显示和变换。

## 播放规则

- 维持当前可见角色每 8 秒播放一次，以及后台、离开可视区域时暂停的规则。
- 同一个角色正在播放时，重复点击不会重新从头播放，避免连续点按导致抽动。
- 减少动态效果开启后，停止分层运动并恢复完整原图，天线不会因底图遮罩而缺失。
- 未解锁关卡不显示人物；已到达及已完成关卡的显示规则与姿态顺序保持不变。
- 须知、复活、锁定弹窗以及答题、成果、学习、积分、证书页复用同一组件。
- 动作不阻塞按钮和导航，不改变答题倒计时、判题、学习记录或积分。
