**趣味闯关 · A 方案美术指导审查 / 2026-10-22**

> 阶段记录：本文保留 2026-10-22／23 的设计决策与当时检查结果。当前规则见 [维护索引](MAINTENANCE.md)，代码质量和远端检查见 [本轮修复记录](20261025-代码质量修复与验证.md)。文中的 qa/ 路径为本地历史存档，未随仓库全部上传，不能当作本轮重新验收。

结论：现有方向可以继续推进，建议完成一轮系统精修后再做美术定稿。插画、主题区分和主要操作已形成基础，但素材质感、视觉主次和小屏阅读空间尚未统一。按本次自定义视觉量表，主观评分为 **70/100**；这是设计判断，不是腾讯内部评分、玩家测试结果或上线结论。

审查对象为当前 `design/approved-home-a` 分支的母工程，以及 2026-10-22 四主题配套流程版本。延续已确认的 A 方案、四套独立主题入口、原横幅、原 IP 和春夏秋冬顺序；审查建议围绕文化学习与乡土探索展开。

本轮查看四主题已有微信模拟器截图，并用当前 WXML/WXSS/Page/Component 源码做浏览器交互检查，生成 80 张状态截图。浏览器主尺寸为 390×844，补查 320×568、430×932 的首页、长题和长解析。使用隔离进度与仓库样题；长题、长解析是现有评审布局样题。没有修改游戏源文件，也没有修改玩家数据。

**应保留的部分**

- 四主题颜色与图形识别已经建立：红色记忆、书卷文脉、麦穗物产、山水生态都能找到对应元素。
- 弯曲路线与交错关卡底座能表达递进；当前关卡保留人物、未来关卡使用锁标记，状态可理解。
- 主要开始按钮足够明确，正确答案还使用了对勾，不只依赖颜色。
- 内页没有继续堆叠装饰性人物。结果页按主题采用鼓手、阅读、丰收、荷叶形象，比所有主题共用同一人物更有内容联系。
- 证书已有独立、完整的纪念物版式，可以作为整套产品的成果资产继续完善。

**P1 / 先处理影响阅读和整体质感的问题**

1. **答题页顶部消耗过多，长题缺乏选项预览。**

   位置：四主题答题页，重点看 320×568 长题。生态主题的实际浏览器测量中，滚动内容区高 212px；题干卡从 y=316 延伸到 y=454，第一项从 y=460 开始，滚动区在 y=466 结束，只有约 6px 的选项容器露出，选项正文不可读。页面仍可滚动，这不是“无法作答”，但用户读完长题后看不到明确的下一步内容。

   修改方向：优先在答题内页压缩重复的主题导语卡、横幅周围空白和非必要标题间距。保留首页横幅的识别作用，内页采用更克制的展示尺寸。长题不要依靠缩小正文来适配。

   验收：相同 320×568 样题在初始位置能读到完整题干和至少第一项的主要文字；其余选项和解析能连续滚动；按钮不覆盖滚动终点；常规选项点击区仍不小于 44px。浏览器复现后，须用微信原生小屏容器再验。

2. **角色、横幅、场景和 UI 的材质没有形成共同规则。**

   位置：四主题首页，尤其看智小谷与关卡底座的衔接。场景采用细腻明暗，横幅采用强高光与厚重卷边，人物采用平涂和粗黑轮廓，说明卡又接近现代平面组件。每个资产本身可辨认，但放在一起有贴图拼装感。

   修改方向：先保留原 IP 和横幅像素，通过人物显示尺寸、柔和脚底接触阴影、底座受光、卡片投影和边线统一来整合。阴影采用短距离、低透明度的椭圆，避免再加硬圆环；交互动作继续以手部和道具为主。

   验收：同一关卡中人物脚底与底座有稳定接触关系，静止和动作切换均不漂浮；卡片、底座、横幅周围的阴影方向一致；不靠全身摇摆或额外闪光掩盖贴图接缝。涉及原资产像素重绘的方案应另行设计评审。

3. **大面积鲜色和粗边框抢走了题目与内容的权重。**

   位置：青山绿水和金色产业的答题、结果、弹窗。当前表现层为生态、产业分别配置了 4px 面板边框；生态边框为 `#52D228`，产业为 `#FEC620`。鲜绿轮廓与大面积浅黄绿底同时存在，画面更像强调活动气氛的外壳，阅读页显得不够安静。

   修改方向：保留四主题的红、棕、金、绿身份；大面积背景减少饱和度，内页框线先试 1–2px。高饱和色集中到主操作、当前节点和必要状态。生态主题品牌色与“回答正确”语义继续通过对勾、边线和填充强度共同区分。

   验收：缩至 25% 看图时，首先能辨认题目、选项和主按钮；边框不会成为整屏最醒目的元素。四主题仍能凭原横幅和小面积主题色辨认。不能把正确状态的对勾去掉。

**P2 / 随后处理的信息与品牌细节**

4. **地图说明卡权重接近，路线被文字切成几块。**

   首页每个节点都展示“第几关、通用名称、状态、首通奖励”四层文字。390×844 浏览器测量中，可见说明卡的矩形面积约占地图视窗的 22.3%；这只是矩形面积，不是视觉注意力测试。实际看图时，大面积白卡和重复文字比场景道具更先被注意到。

   修改方向：保留当前关卡完整信息；未来关卡优先展示章节主题与锁定状态，奖励作为次级信息。使用现有“山水初识、自然观察、生态守护”等主题副标题加强内容识别，同时保留服务提供的正式关卡名和顺序。调整卡内留白和信息层级，沿用 A 方案坐标，不恢复已经排除的 B 方案。

   验收：用户能直接指出当前可参与的一关；未来关卡退居次级。简化后仍能通过点击查看规则和奖励，不能只减字号来塞字。

5. **字体使用清楚，但标题个性与界面层级仍偏普通。**

   横幅标题、关卡名、状态和主按钮普遍使用强字重；首页的“深度应用”和“当前关卡”同时较重，缺少更明确的阅读先后。文化文脉的横幅画得丰富，标题字形却比较通用。

   修改方向：先统一三档字重和间距：标题负责识别，正文负责阅读，状态和奖励负责补充。正文保留现有易读黑体；主题字形作为后续品牌专项设计，不建议直接把正文替换为书法字体。

   验收：灰度看图仍能按“章节主题→当前状态→奖励说明”阅读；数字在积分、正确率与进度中保持一致的对齐方式；长题自然换行。

6. **结算页有结果，但“学到了什么”的记忆弱于数字。**

   目前已经有主题人物、主题概括、正确率、积分和下一关入口。问题在于四主题仍沿用相近统计布局，最醒目的是 100% 与 +10，实际文化内容成为下方一句概括。

   修改方向：提升现有主题概括与下一章节内容的联系；单关完成使用短促、克制的反馈，主题全部完成时再突出已有证书。只使用已配置的章节与学习内容，不能编造用户掌握了某个知识点或新增收集系统。

   验收：完成页同时能回答“完成了哪一章、获得了什么、下一步是什么”；单关完成和整个主题完成能明显区分，仍保持一个最主要的继续操作。

7. **证书与游戏外壳的气质存在跳转，需要用呈现方式衔接。**

   证书采用庄重的纸张、金色字和边框，页面外壳仍然明亮卡通。这可以是一种合理的正式感转换，但目前大横幅、粗面板与正式证书同时出现，容易互相争夺注意力。

   修改方向：保留已确认的证书版式和数据；证书展示区域的周围装饰减量，突出完整预览、保存和分享。完整证书用现有点击预览承接，避免在小窗里把正文缩得过小。

   验收：证书缩略图可以识别主题、证书名称和获证人；点击后能看完整内容；保存图片与预览使用相同证书资产。

**建议实施顺序与复核方式**

第一轮只做三件事：小屏答题释放空间、生态／产业内页色彩与边框减量、首页当前／未来节点的信息分级。第二轮整合人物落地感和 UI 材质。第三轮再处理标题字形、完成反馈和证书展示。每轮都使用同一组初始、选中、正确、复活、锁定、结算状态做前后对照，避免通过替换样题或进度让画面显得更好。

建议先以青山绿水做样板确认视觉规则，再同步其他三主题。修改完成后的目标是：保留 A 方案的辨识度，减少同时高亮的东西，让文化内容和当前操作更容易被看到。
