# 两款首页风格评审

当前流程是先给领导看两款明显不同的首页，选定风格后细化。原版 `main` 与 `baseline-20261021-before-home-options` 标签保留；此次修改位于 `design/home-two-directions`。

| 方向 | A · 插画漫游 | B · 色块章节 |
|---|---|---|
| 主视觉 | 铺开的插画路线 | 色块人物章节主卡 |
| 章节形态 | 圆形底座、交错说明 | 当前主卡、其余章节卡片目录 |
| 控件 | 浅色入口、主题渐变主按钮 | 独立入口卡片、实色主按钮 |
| 人物 | 站在已到达路线点位 | 站在已到达章节卡内 |
| 配色 | 原有明亮主题插画 | 红／棕／金／绿明确的界面色块 |

B 严格依据用户选择的 [Figma 原参考 image 65 / 1:67](https://www.figma.com/design/WYrdxvwRhk0e7k1sj3mK4c/Untitled?node-id=1-67) 的色块、人物卡片与分区形式实现。参考原图附在评审页，可点击回到原位置。未采用未通过的生成长卷，不继续自绘背景。

原参考是位图；原生界面重建其卡片形式，并按甲方的主题色、横幅与 IP 约束适配内容，不声称像素复刻原英文情绪 App。

四主题分别进入自己的首页，无正式四主题汇总入口。B 通过既有 `homeDesign:'guide'` 接口启用；`current` 和 A 的 `map` 保持原有表现。四套正式工程继续默认 `current`，选型前不切换。
