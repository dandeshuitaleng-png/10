# 两款首页设计

当前版本已推送到 GitHub `main`，提交 `ba141c2e9b2e7e8c03037a0c5805e1d0877d14f6`，保留标签 `baseline-20261021-before-home-options`。新设计位于 `design/home-two-directions` 分支。

## 设计内容

| 方向 | A · 插画漫游 | B · 柔彩绘本 |
| --- | --- | --- |
| 信息顺序 | 主题标题 → 主题短句 → 进度与入口 → 插画路线 | 主题标题 → 主题短句与进度 → 入口 → 暖纸画框内路线 |
| 视觉重点 | 连续、铺开的插画地图 | 柔和主题色、暖纸底板、哑光主题按钮 |
| 适合呈现 | 探索感、完整的主题场景 | 更轻盈的绘本质感，关卡插画作为唯一主视觉 |
| 保留内容 | 原标题横幅、原插画、原 IP、节点状态与动画 | 原标题横幅、原插画、原 IP、节点状态与动画 |

按最新反馈，B 款取消顶部人物和导览卡片。用鼠尾草绿、陶土红、麦金和暖棕区分四主题，插画使用暖纸底色衬托，保留原画造型与关卡人物。A 款继续使用鲜明的主题色与渐变按钮。

四个主题分别完成 A、B 首页，共八张原生评审图。主题色沿用红、棕、金、绿；金色产业继续使用麦金横幅和麦穗，青山绿水保留绿色山水横幅。没有新增四主题汇总入口。

## 接入范围

- 四套正式工程的 `game-config.js` 不增加布局选择字段，继续默认 `current`；评审参数不能开启正式工程的评审功能。
- 隔离评审工程通过 `review=1&homeDesign=map` 或 `review=1&homeDesign=guide` 查看新首页。
- 领导选型后可在选定工程中配置 `homeDesign:'map'` 或 `homeDesign:'guide'`，不改变学习服务及存档。
- 评审页的主题切换与 A/B 入口只存在于评审工具中。

## 已完成验证

- 自动回归 90 项：39 项学习服务、34 项实际 Page 生命周期及行为、9 项首页布局与选择边界、3 项主题内容、5 项连续按压反馈。
- 微信原生渲染：4 主题 × 2 款 × 3 尺寸，共 24 组布局检查；另有 2 组主按钮和返回导航检查。
- 检查覆盖标题中轴、标题字位置、44px 入口、地图实际尺寸、当前关卡卡片、智小谷可视区域、底部操作按钮安全区。
- 原生截图恢复开发者工具实际屏幕几何后拍摄；约束容器截图另存，未作为领导评审图。
- 主工程和四套独立工程共 5 套 `wcc`、`wcsc` 编译与资源体积检查通过，最大主包 1.679 MiB，低于 2 MiB。
- 浏览器评审页已检查主题切换、B 款进入章节须知与返回。后续浏览器检查记录见 `qa/home-designs-20261021/browser-checks.json`。

原生渲染检查与浏览器检查是开发验证，不代表本轮已经完成 iPhone、安卓微信的真机验收或微信平台发布。
