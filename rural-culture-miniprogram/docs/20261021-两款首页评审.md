# 两款首页风格评审

当前流程是先给领导看两款明显不同的首页，选定风格后细化。原版 `main` 与 `baseline-20261021-before-home-options` 标签保留；此次修改位于 `design/home-two-directions`。

| 方向 | A · 插画漫游 | B · 探索卡册 |
|---|---|---|
| 主视觉 | 铺开的插画路线 | 主题底板上的故事卡册 |
| 章节形态 | 圆形底座、交错说明 | 场景画窗、叠层纸卡、问号封面，所有关卡同尺寸 |
| 控件 | 浅色入口、主题渐变主按钮 | 纸卡工具入口、主题编号签、完成印章及渐变按钮 |
| 人物 | 站在已到达路线点位 | 已到达卡片中显示原 IP 与各关动作 |
| 配色 | 原有明亮主题插画 | 红／棕／金／绿底板，白色卡面与主题色当前边框 |

B 形式依据用户选择的 [Figma 原参考 image 65 / 1:67](https://www.figma.com/design/WYrdxvwRhk0e7k1sj3mK4c/Untitled?node-id=1-67) 的色块、人物卡片与分区形式实现。参考原图附在评审页，可点击回到原位置。未采用未通过的生成长卷，不继续自绘背景。最新补充参考为用户指定的 [故事卡册图 74 / 1:76](https://www.figma.com/design/WYrdxvwRhk0e7k1sj3mK4c/Untitled?node-id=1-76)，采用主题卡册底板、叠层纸卡、原场景切片画窗、编号签、完成印章、问号封面与分段进度。当前关不再放大；四关字号、宽度和高度相同，最长章节名称决定整组高度。

原参考是位图；原生界面重建其卡片形式，并按甲方的主题色、横幅与 IP 约束适配内容，不声称像素复刻原英文情绪 App。

四主题分别进入自己的首页，无正式四主题汇总入口。B 通过既有 `homeDesign:'guide'` 接口启用；`current` 和 A 的 `map` 保持原布局。客户最新要求的统一横幅、局部手部动作同步三种表现，见 [本轮修订说明](20261021-局部动作与横幅统一.md)。四套正式工程继续默认 `current`，选型前不切换。
