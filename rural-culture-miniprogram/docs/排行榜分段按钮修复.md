# 排行榜分段按钮越界修复（2026-10-17）

## 现象与定位

四套主题共用的排行榜按钮使用两列1fr网格。微信模拟器中的按钮固有宽度为184px，将两列撑大。以金色产业为例，外框右界370px，总榜按钮右界397px，超出27px；浏览器预览原先没有复现。

## 修改

母工程及四套独立工程的pages/game/index.wxss中，将分段网格改为minmax(0,1fr)等分列，并明确按钮width:100%、min-width:0、margin:0、padding:0、border-box。保留44px点击高度和各主题选中配色。没有修改排行算法、首页、题库、存档或后台。

## 已验证

- 金色产业微信模拟器修复前几何检查失败，修复后通过：两按钮各168px，左右均内缩5px，间隔4px，高44px。
- 四套主题在320×568、375×812、430×932下，每日榜和总榜共24组浏览器布局及真实点击检查通过。浏览器亚像素高度允许0.5px舍入误差。
- 母工程及四套独立工程的JS/JSON、原生WXML/WXSS编译通过。
- 四套构建清单280个文件的哈希与当前源码一致。

## 原生自动化限制

追加四套模拟器周期切换检查时，部分导航调用超时，部分tap返回成功但界面没有切换。此类结果不计为通过；原生完整交互验收与浏览器检查分开记录。工具v4-rank-tabs-check.py可在排行榜已打开时检查几何，--period通过页面事件处理器设置周期，用于布局回归，不等同于实际触摸验收。

证据见qa/ranking-tabs：before-native.json、industry-final-native.json、browser-report.json、compile-report.json及修复后截图。
