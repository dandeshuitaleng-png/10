## 已修正的问题

| 原表现                     | 当前表现                                                                                     |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| 生成中仍显示普通保存按钮   | 显示生成状态及“正在生成证书…”，就绪后才能保存                                                |
| 所有保存错误都提示检查权限 | 区分生成失败、权限被拒、主动取消和普通保存失败；分别提供重新生成、相册设置、轻提示或直接重试 |
| 生成失败后刷新可能反复尝试 | 保留失败状态，等待明确点击重新生成；旧任务不会替换后发任务的结果                             |
| 相册权限被拒后缺少入口     | 提供“打开相册设置”；允许后提示再次点击保存，不自动写入相册                                   |
| 分享弹窗的主操作是结束预览 | “分享给朋友”为原生微信分享按钮，“返回证书”为次操作                                           |
| 保存成功只显示短暂提示     | 页面保留成功反馈；浏览器下载明确提示“已发起证书图片下载”                                     |
| 保存期间可能重复请求       | 单次保存保护；退出页面或卸载后的回调不再弹成功或覆盖新页面                                   |

预览和保存继续使用同一张生成 PNG，不重新设计证书正文、边框、获奖规则、历史关卡范围、编号或落款。证书切换至少 44px 点击区；生成状态使用 24px 图标、18px 标题、14px 说明和统一细边框卡片。微信分享继续保留服务配置的封面与当前主题路由，不将预览视为已送达朋友。

## 真机验收顺序

1. iPhone 与安卓各从未获证完成学习到领取证书，核对姓名、主题、日期及历史关卡范围。
2. 打开完整预览，保存至相册并核对实际图片；检查首次询问、拒绝后设置、再次保存及主动取消。
3. 分享给指定测试账号，核对收到的标题、封面和打开后的主题页面。
4. 复查地图人物滚动重影、小图标清晰度、长文字及底部安全区。

手机、测试账号及对应实测记录具备后才能将上述四项标为通过。
