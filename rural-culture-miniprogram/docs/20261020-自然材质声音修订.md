# 自然材质声音修订

用户指出原短音效“太电子、突兀，与主题形式不结合”。本次替换短音效的来源与触发节奏，四主题同步；不改变界面布局、角色或业务规则。

| 场景 | 本次声音 |
|---|---|
| 普通导航、打开关卡说明 | 安静，只保留视觉反馈 |
| 开始答题、进入下一题 | 一次柔和纸页翻动；成功切换后才播放 |
| 选择选项 | 轻木质触点；重复点同一选项不响 |
| 答对 | 不同的轻木质确认声 |
| 答错、锁定 | 保留文字与图形提示，去掉负向警报音 |
| 点击人物 | 一次短促的树叶沙沙质感，配合角色动作 |
| 完成关卡 | 与背景音乐同源的约一秒钢琴片段，替代原跳跃式电子提示 |

纸页来自 StarNinjas 的 [10 Book Page Flips](https://opengameart.org/content/10-book-page-flips)；木质、树叶声音来自 TinyWorlds 的 [Different steps](https://opengameart.org/content/different-steps-on-wood-stone-leaves-gravel-and-mud)。这两组来源为物理材质录音，页面均标注 CC0。钢琴继续使用 Joth 的 [JRPG Piano](https://opengameart.org/content/jrpg-piano)，同样标注 CC0。选用文件经过裁切、滤波、增益与淡入淡出，没有添加合成振荡音；选材、参数与 SHA-256 见 `design-source/audio-natural-20261020/`。

背景音乐音量从主页 0.23/答题 0.12 调整为 0.12/0.07，渐入延长至约 1.2 秒。不同短音不叠放，连续触摸间隔至少 220ms；答题结果优先播放，其短暂期间不插入触摸声。静音选择、后台暂停、视频题避让继续保留。

运行资源为六个 MP3（含背景音乐），共 222,676 字节。旧电子音已从四套运行资源中移除。12 秒试听按当前音量稀疏安排，不是密集串烧或手机录音；最终听感仍需用户试听确认。

验证记录位于 `qa/audio-natural-20261020/`：8 项音频与 4 项网络页面回归、32 项实际 Page 检查通过；母工程及四套独立工程编译通过，包体均小于 2 MiB。完整解码六个 MP3，无削波样本。青山绿水四项原生交互与六个音频播放回调通过；其余主题通过共享源文件一致性校验。本次扫码预览生成在 180 秒超时，未产出新二维码。以上检查不能推断实体手机听感或正式发布状态。

本次音色修订的工程包为 `交付/四主题独立工程-自然声音修订-20261020.zip`；后续已加入独立音量与开关面板，详见 `20261020-声音设置面板.md`，最新包为 `交付/四主题独立工程-声音设置版-20261020.zip`。先前“声音版”包与试听是上一版素材，保留为历史记录。
