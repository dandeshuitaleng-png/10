## 视觉与动作

配色：十步芳草 `#B94237 / #FFF0EA`；千年文脉 `#8B6246 / #F4EBE2`；金色产业 `#B9841B / #FFF7DE`；青山绿水 `#42835A / #EFF7E9`。蓝色保留为其他分类预留色。

A 保留原插画，使用暖纸卡片和微立体按钮。B 在原插画上使用 20% 浅色主题覆盖，卡片为白纸、细边框和左侧色标，主按钮使用实色。原标题和节点位置两款一致。

角色为统一二维矢量形象，不使用整图漂浮替代局部动作。主身体固定，四组时长依次 1 / 1 / 1.2 / 1 秒。当前可用节点进入可视范围时播放一次，每 8 秒再次播放；其他可见节点点击时播放一次。页面隐藏、节点离开可视范围或减少动态效果开启时，取消动画及待播放计时。动画由独立控制器管理，不改变答题倒计时。

角色尺寸：320px 屏幕 56×66px，375px 屏幕 64×76px，430px 屏幕 72×84px。角色完整画布与说明卡的最小间隔检查为至少 8px，局部动作位于画布范围内。地图图片、地图比例、业务关卡顺序与规则保持原约定。

## 工程范围

母工程、四套独立工程、总入口内嵌游戏页已同步组件、样式、地图展示与动作控制器。PC 复用同一原生源页面，并增加新角色组件的静态资源白名单。总入口只更新青山绿水的横幅资源引用，首页结构未改。

后端判题、存档服务、身份逻辑和原三个标题文件均通过修改前后哈希核对。没有新增业务 API 或数据库迁移。手动减少动态效果保存于独立前端展示偏好键，不覆盖学习记录。
