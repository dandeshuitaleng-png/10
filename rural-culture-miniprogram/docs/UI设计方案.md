# 趣味闯关 · 乡村文化知识探索

本次设计以用户 2026-10-13 提供的需求为准，四个主题为十步芳草、千年文脉、产业振兴、绿水青山。定位为数字文化阅读与知识探索平台。

## 页面结构与交互

首页 → 四大文化专题 → 主题章节目录 → 知识答题 → 解析 → 章节完成 → 下一章节。

答题未通过 → 继续学习弹窗 → 分享复活 → 返回原题继续；次数耗尽 → 今日暂停 → 返回主题。所有资格由 services 返回。首页同时通往我的学习、学习积分榜和电子证书。

| 页面 | 内容与设计 | 主要行为 |
| --- | --- | --- |
| 首页 | 项目标识、读本式标题、原创湘村山水、介绍、开启探索、学习概览 | 进入专题、学习记录、排行榜 |
| 主题选择 | 四张统一卡片，主题插画、描述、章节完成度 | 进入对应主题 |
| 章节目录 | 主题引言、完成进度、顺序章节、完成/可学/未解锁状态 | 已完成可重读、当前章可参与、锁定项说明 |
| 知识答题 | 主题章节、题号、进度、计时、动态选项、可选图片/视频、结果解析 | 提交到服务层、查看解析、继续 |
| 继续学习弹窗 | 未通过提示、解析、复活次数、分享入口、返回主题 | 分享后申请资格、次数耗尽后显示暂停状态 |
| 章节完成 | 正确率、获得积分、累计积分、下一章、主题入口 | 继续章节、领取已获得证书 |
| 电子证书 | 已获得主题证书和总证书、姓名、日期、编号、保存及分享 | 切换证书、生成图片、保存相册、分享 |
| 学习积分榜 | 每日/总榜、昵称、名次、积分、自己的成绩 | 切换榜单 |
| 我的学习 | 章节进度、累计积分、证书数量、最近学习 | 继续阅读、查看证书 |

## 统一视觉规范

视觉记忆点：宣纸底色上的原创山水长卷，村落、稻田与书页形成连贯的文化阅读氛围。主题仅改变强调色与插画，组件布局一致。正文与操作文字不使用浅金色，保证阅读对比。

| 类别 | 规范 |
| --- | --- |
| 基础颜色 | 宣纸白 #F7F3E9；竹青绿 #315C4C；古铜金 #B39A70；朱砂红 #9A5147；墨灰 #333C39 |
| 辅助颜色 | 卡片 #FFFDF7；次级文字 #66736C；分隔线 #DEDCCD；产业强调 #795924 |
| 字体 | 正文系统无衬线：PingFang SC / Microsoft YaHei / sans-serif；主要文化标题用系统宋体，Figma 使用 Noto Serif SC；不嵌入商业字体 |
| 字号 | 页面标题 28–36px，章节标题 20–24px，正文/选项 17–18px，辅助文字 14px，正文行高 1.65 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px；手机左右 24px，窄屏 20px；区块间 24px |
| 按钮 | 主按钮深绿/主题色，白字，最小 48px；描边次按钮；提交中和禁用有独立状态；无夸张阴影 |
| 卡片 | 宣纸浅色底，12–16px圆角，细边框；图文内容留白；章节使用简洁目录式列表 |
| 动画 | 160–220ms淡入与颜色过渡，尊重减少动态效果偏好 |
| 适配 | 320–430px纵向单列；宽屏主题卡片两列；主体宽度上限960px；底部操作避开安全区 |

## 模拟配置与接入边界

演示配置为四个主题各四章，每章三题，共48题。题目、章节名、顺序、积分、时间和复活次数均由配置与服务层读取，演示数据不能视为甲方正式题库。正式题数和过关条件应由后端配置确定。

页面只能获得题干、素材、选项和服务端截止时间，不接收答案字段。第一阶段的标准答案位于 `services/mock-server/`，只供模拟服务使用；生产模式采用远端适配器，并且打包时应删除 mock-server，避免携带答案。生产后端负责身份认证、判题、截止时间、解锁、积分幂等、复活资格、每日锁定和证书签发。

分享动作并不构成可靠的分享成功证明。原型仅演示“分享返回后向服务申请复活”的交互；正式资格须由产品确定可验证机制，并由后端返回，不能以客户端回到前台当作分享成功。

原创插画由本项目绘制，保留 SVG 源文件及小程序使用的 PNG，不使用第三方商业素材。
