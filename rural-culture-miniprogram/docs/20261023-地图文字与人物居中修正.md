## 本轮修正

已完成卡片原为 76px，四行文字使用较大的行高且允许 Flex 压缩，标题行因此被挤压。现在保留已完成 76px、当前 90px、未解锁 64px 的高度，逐行保留完整行框：

| 文字           | 当前字号／行高 |
| -------------- | -------------- |
| 关卡序号与名称 | 10／14px       |
| 当前关卡标题   | 16／22px       |
| 已完成关卡标题 | 15／20px       |
| 未解锁关卡标题 | 14／20px       |
| 关卡状态       | 11／15px       |
| 积分提示       | 10／14px       |

四行文字不再被压缩；卡片保持与底座的水平对应，按压反馈仍围绕同一中心进行。长的辅助关卡名称使用单行省略，完整名称继续保留在按钮的无障碍描述中。

人物改用主身体的脚底锚点，不将道具、花朵、落叶或雪人计入站立中心。四季人物脚底都对准 220×165 原底座图的台面中心（110，65）；坐标随底座一起滚动，地图仍只使用单层动作帧，不引入 Canvas 或第二层完整人物。可见性判断使用实际脚底位置，离开视区与滚动期间保持既有暂停行为。

实现涉及 `pages/game/map-legibility-20261023.wxss`、`services-v4/home-layout.js`、`journey.js`、`mascot-rig.js` 和 `components/mascot-actor/index.wxml`。其他页面的人物取景保持既有方式。
