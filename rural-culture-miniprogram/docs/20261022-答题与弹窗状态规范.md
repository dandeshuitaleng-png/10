# 答题与弹窗状态规范

> 阶段记录：本文保留 2026-10-22／23 的设计决策与当时检查结果。当前规则见 [维护索引](MAINTENANCE.md)，代码质量和远端检查见 [本轮修复记录](20261025-代码质量修复与验证.md)。文中的 qa/ 路径为本地历史存档，未随仓库全部上传，不能当作本轮重新验收。

本轮承接图标与卡片统一，修订答题、解析、未通过、超时及锁定状态。四主题共用组件规则，保留原插画、原人物、主题配色、题目字号与浅渐变按钮。题库、关卡规则、复活次数和计分逻辑不变。

| 状态     | 呈现与操作                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------- |
| 未选择   | 20px 空心状态圈，提交按钮不可用                                                                                         |
| 已选择   | 主题色边线与浅底、实心选择点；字母和状态圈相对整张选项卡垂直居中                                                        |
| 核验中   | 保留选择结果，按钮提示正在核验并阻止重复提交                                                                            |
| 答对     | 16px 白色对勾完整放在 20px 状态圈内；绿色边线、浅底与正确答案标签共同表达；其余选项保持只读、使用辅助文字色，字号不缩小 |
| 未通过   | 20px 信息图标配“本次回答未通过”，继续说明复活机会，不提前透露答案                                                       |
| 超时     | 20px 时钟配“本题暂未完成”；剩余 8 秒及以下时，计时区增加浅色底和边线，不使用闪烁                                        |
| 今日锁定 | 20px 锁图标配锁定说明，继续保留次日开放时间与已有积分说明                                                               |
| 弹窗控制 | 关闭图标统一 20px，原有 44px 点击区域不变；主操作至少 52px，次操作至少 44px                                             |

选项字母去掉内高光，使用同一圆框与居中规则。辅助文字在白色选项面上的计算对比度为 5.15–5.95，四主题都保持可读。正确状态保留绿色与勾选的共同表达，未通过、超时和锁定也同时有文字与图形。

浏览器预览补齐弹窗焦点管理：打开时移入弹窗，Tab／Shift+Tab 在当前弹窗循环，背景从键盘和浏览器无障碍树中暂时退出，关闭后返回触发按钮。声音设置、须知、答题退出和嵌套系统提示使用同一机制。弹窗内的数字键与 Enter 不再触发背景答题；当前按钮仍可通过 Enter 正常操作。原生页面补充弹窗角色与名称。本轮未进行完整读屏或实体手机验收。

当前浏览器页面源码通过 148 组检查，覆盖四主题、320×568／390×844／430×932 的首页、答题、选中、长题、正确解析、长解析、复活、锁定、须知、结算、证书和声音设置，以及实际提交。记录见 `qa/art-refinement-20261022/browser-checks.json`。

专项 17 组检查覆盖键盘循环与返回、声音设置、嵌套提示、弹窗阻断背景快捷键、真实选择→提交→下一题，以及四主题紧急计时、未通过、超时图标。记录见 `qa/quiz-states-20261022/browser-checks.json`。评审时钟固定，紧急计时和超时截图是明确设置的展示样本，不作为真实倒计时或正式分享复活验证。
