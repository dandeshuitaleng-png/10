# 四主题地图与控件统一 · 2026-10-18

本轮统一首页中间关卡区的场景比例、滚动条件和控件几何。各套已确认的标题、外围配色、底部按钮材质及业务状态保留。

## 场景与滚动

四张原图均为750×1280。统一场景高度=实际宽度×1280÷750，按原图比例显示，不按视口高度压缩、裁切或拉伸。四关以内保留完整一张场景；更多关卡按配置顺序扩展完整场景，不把四关写成业务总数。

| 窗口宽 | 场景高度（逻辑px） |
| ---: | ---: |
| 320 | 546.13 |
| 375 | 640 |
| 390 | 665.60 |
| 430 | 733.87 |

仅地图区滚动，顶部和底部按钮固定。场景超过可视区时四套统一允许上下滚动，进入首页定位当前关卡；没有当前关卡时按今日锁定关卡或最后关卡定位。空目录不滚动；大屏完整容纳场景时不制造空白滚动。

390×844模拟器下，文化/红色/产业地图可视高度497px，可滚动约168.59px；生态保留176px初代顶部，地图可视高度516px，可滚动约149.59px。区别仅来自保留的标题区域，四套场景与控件规则相同。当前关卡卡片底部保留至少16px可见余量。

## 控件规范

相同屏宽下，四套使用相同的地图相对坐标、尺寸与间距。关卡从下到上依次采用原图坐标(67%,85%)、(30%,64%)、(67%,42%)、(26%,24%)；更多关卡接续下一张场景。

| 元素 | 390px宽度的尺寸或规则 |
| --- | --- |
| 节点容器 | 100×89px |
| 节点原图 | 100×75px，顶部6px |
| 关卡编号 | 30px字体、36px行高 |
| 关卡卡片 | 137×90px，13px圆角 |
| 卡片与节点 | 水平10px，垂直中心对齐 |
| 状态标记 | 26×26px，节点右7px/下6px |
| 引导角色 | 60×70px |
| “在这里” | 64×20px，与角色间距−3px |
| 底部主按钮 | 358×52px，左右16px |

节点随屏宽有界缩放，卡片宽度限制124～150px。320px小屏角色为48×58px、提示为60×20px；四主题使用同一断点与参数。卡片仍在节点对侧，角色在外侧；包含提示外沿的左右安全间距至少8px。当前、完成、锁定节点图与文字状态继续读取现有服务。

共用参数位于services-v4/home-layout.js的mapMetrics；场景与焦点位于services-v4/journey.js，布局样式位于pages/game/home-layout.wxss。母工程与四个独立工程的这三份文件及首页JS/WXML同步一致。
