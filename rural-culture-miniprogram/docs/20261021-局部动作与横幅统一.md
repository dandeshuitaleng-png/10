# 局部动作与四主题横幅统一

依据客户最新两张聊天截图：智小谷以手、脚等局部动作表达互动，取消整个人物左右摇摆；四主题标题参照产业与生态的展开折叠缎带统一。本轮保留已认可的 A 插画漫游、B 探索卡册及红／棕／金／绿主题体系。

## 人物

- 原四张 PNG 不修改像素、轮廓或头身比例。用原图局部遮罩提取手臂，底图在同一区域留孔，配小幅手腕转动；身体、头和脚底固定。
- 四关分别使用风车手腕、相机造型举手、糖葫芦手、冰淇淋手的小动作。延展形象保留各自手部、道具动作，移除整体场景层摇晃。
- 去掉人物按钮的整体缩放；普通按钮仍保留既有按压反馈。到达、完成、未解锁、今日锁定及连续点击控制器不改。
- 后台、不可见与系统减弱动态继续暂停；减弱动态时显示完整原静态图。时长仍为 1.8／2.1／2.3／1.9 秒。

这次是原位图的局部分层动作，不是骨骼动画，也未重新绘制 IP。移动手臂背后的底色由小面积界面遮罩补齐；透明原图与脚部像素保持不变。

## 标题

红色与文脉新横幅以产业、生态两张已确认横幅为图像编辑参考。产业麦金麦穗、生态绿色山水保留；红色保持橙红缎带，文脉使用木棕缎带和淡云纹。四张属于同一折叠缎带家族，中央书写区统一承载实际界面文字。

高分辨率源图、完整提示词与运行导出路径见 [素材说明](../design-source/title-ribbons-20261021/README.md)。两张运行图为 1050×350，约 53／63KiB。正文是独立文本；红色、文脉主页字号 24px，按中文字形校正基线并保留上下边距。内页、弹窗、分享封面同步新横幅与标题定位。

## 核查与边界

- `tests/local-mascot-motion.test.cjs`：四张原 PNG 哈希、手部裁切不触及脚部、身体层无动画绑定和静态回退。
- `qa/home-designs-20261021/local-motion-checks.json`：微信原生隔离页的静止／560ms 定格；四姿态脚部轮廓质心差异最大 0.519 截图像素、边界最大 1 像素。保留 GPU 抗锯齿容差，不能作为逐像素零差异或流畅度验收。
- `native-checks.json`：A／B 四主题在 320×568、375×812、430×844 约束容器中的布局与导航。430 高度保持在模拟器可视区域内，避免容器外自定义组件被裁剪；不是 430×932 真机结果。
- `b-regression-summary.json`：动作、分享封面、100 次按压与取消、首页和实际 Page 回归。历史运行按时间保留，本轮追加记录。
- `shared-ribbon-checks.json`：红色／文脉答题与须知弹窗的新横幅、文字区域检查和原生截图。原生屏幕圆角外的截图边缘可能包含工具窗口残片，不作为页面内容。
- `compile-summary.json`：母工程和四独立工程原生编译与有效包体检查。独立工程排除另外主题的新横幅。

图片检查和原生模拟器结果不等于实体手机验收。浏览器控制当前关闭，本轮只检查 HTTP 实际交付内容，不记录浏览器交互通过。未上传或发布微信版本。
