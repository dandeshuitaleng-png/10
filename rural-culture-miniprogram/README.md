# 趣味闯关 · 原生联网版

10 月 19 日的四主题配色、原图角色与当前首页见 `docs/20261019-反馈修改说明.md`；双击根目录 `查看反馈修改.command` 打开当前方案。

联网入口、运行配置和验收结论以 `docs/联网整合交付说明.md` 为准。旧视觉评审记录保留供对照。

本项目与四套独立主题、平台总入口、PC参与页和原管理页面共同读取同一个本地后端。原生默认 `mode: 'http'`，不携带正式题目的标准答案，不以本地引擎替代联网判题。

先在上一级 `demo` 执行 `node scripts/start-local-service.cjs`，访问 `http://127.0.0.1:63112/play` 参与；管理页面直接打开 `http://127.0.0.1:63112/manage`，无新增登录界面。原有Vite开发入口仍是 `http://127.0.0.1:5190/`。

微信开发者工具导入本目录或 `交付/微信小程序四套` 内对应工程。当前配置仅用于本机联调：`http://127.0.0.1:63112` + `identity: 'local-shared'`。四套、总入口与PC共用本机体验账号，用户真实身份尚待甲方接口；不得按多人正式账号部署此适配。

原生总入口工程 `平台总入口` 已集成四主题页面；首页 `pages/portal/index`，进入主题 `pages/game/index?theme=culture|red|industry|ecology`。四份独立工程仍保留各自主题入口。总证书按后端启用目录的稳定关卡ID生成，默认16关、300积分、5张证书。

网络失败会保留服务器历史和待重试操作编号；重新连接会恢复结果，不重复加分。旧 `rural-quiz-native-v4:*` 存档保留且不作为已验证积分导入。无需清理浏览器或微信存储。
