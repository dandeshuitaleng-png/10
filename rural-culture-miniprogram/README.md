# 趣味闯关 V2 · 国风手绘文化探索

原生微信小程序 UI 原型，WXML + WXSS + JavaScript，无第三方 UI 库。包含首页、四大主题、章节目录、答题、继续学习/复活弹窗、结算、主题/总证书、学习积分榜和我的学习。

V2设计定位为“新中式文化探索游戏”，采用五幅独立AI生成国风绘本场景、画卷书签路线与宣纸答题书页，四主题具有不同建筑和自然景物。没有金币、宝箱、三星或游戏地图。

## 打开项目

在微信开发者工具导入本目录，项目类型选择“小程序”。本机验证使用当前账号的小程序测试号；其他账号请把 `project.config.json` 的 `appid` 换成自己的测试号或小程序 AppID。

无需安装依赖、无需连接数据库。首次打开首页，点击“开启探索”即可演示。演示状态保存在当前项目本地存储中，可保留学习进度；重新开始演示时，只移除该项目的 `rural-culture-ui-v1` 存储项。

浏览器预览：运行 `node tools/serve.cjs`，打开 `http://127.0.0.1:4173`。预览直接读取小程序的页面、样式、组件和服务代码。浏览器分享与相册保存以演示弹窗、下载文件模拟；实际微信行为应在小程序中验证。

## 演示流程

首页 → 文化专题 → 章节目录 → 选择答案 → 提交 → 阅读解析 → 下一题 → 学习成果 → 下一章节。

答错可进入继续学习弹窗：分享返回后向模拟服务申请复活，重新回答原题；再次答错会暂停当日参与。微信的分享调用不能可靠证明分享成功，本地原型只模拟业务资格。正式后端必须自行确认复活资格，客户端不会签发资格。

每个主题四章，每章三道演示题，共48题；选项数量支持变化，产业首题展示图片，题目模型也支持视频。通关积分示例为10/15/20/30，每章只领取一次；主题全部完成获得主题证书，四大主题全部完成获得总证书。题库、规则和榜单均为演示资料，需要正式内容审核和业务配置。

## 后端接入

页面不导入题库、不比较标准答案。`services/index.js` 提供统一接口，`services/remote.js` 使用 `wx.request`。正式上线需要后端认证、真实题库、服务端时钟、幂等请求、解锁和奖励校验、证书签发与媒体资源域名。

运行 `node tools/prepare-remote.cjs https://你的后端地址` 可生成独立的 `delivery-remote/` 接入包，排除全部模拟答案和模拟服务。设置 AppID 与微信后台合法域名后再对接。该包是接入骨架，不代表正式后端已完成。

## 检查与证据

`node tests/services.cjs` 验证服务流程；`node tools/check.cjs` 检查语法并调用本机微信 WXML/WXSS 编译器。浏览器测试需要 Playwright 与 Chrome；当前验证使用 Codex 的工作区依赖。测试脚本中的依赖路径仅用于本机 QA，小程序本身不依赖这些工具。

具体检查结果和原生验证范围见 `docs/验证记录.md`。浏览器、原生模拟器、真机和正式后端证据分开记录。
