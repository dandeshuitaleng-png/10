# 组件与排版规范

以用户四张模板的配色、轮廓和材质为视觉基准。只共用排版、功能状态和组件结构，四个独立游戏分别保留其美术表现。

| 项目 | 规范 |
| --- | --- |
| 基准 | 375×812；手机竖屏；PC保持375px宽游戏画面，短屏缩短容器高度 |
| 安全区 | 顶部44px原生区域，底部34px；原型中为模拟展示 |
| 内容 | 左右20px，375基准内容宽335px；外容器左右12px加内部8px，绿色4px边框计入20px |
| 间距 | 8 / 12 / 16 / 24；选项间距8px，题卡到选项16px |
| 题目 | 系统宋体20px / 30px，深炭灰#222；无商业字体依赖 |
| 文字 | 答案16px / 24px，辅助正文14px；紧凑数据说明12px，原生与模拟标识10px |
| 图标 | 主图标24px；图文行辅助图标16–18px，独立操作热区44px |
| 题卡 | 纯白，圆角14px，内边距16px；媒体144px高；无媒体时不留空位 |
| 选项 | 默认56px高；字母28px、右侧状态20px；所有长选项同步增高，不截断 |
| 主操作 | 宽335px（基准），高52px；金色切角，其余胶囊；按下位移2px |
| 次操作 | 高44px，低强调浅底描边；与主操作间距8px |
| 滚动 | 题号、倒计时、进度固定；题干、媒体、选项、解析在内容区滚动；底部按钮独立，不盖住内容 |
| 小屏 | 低于700px高时压缩题头与首页插画，插画128px；剩余内容滚动 |
| 弹窗 | 当前游戏皮肤、独立题头装饰、背景模糊、单个.modal-mask；不叠加第二个弹窗遮罩 |

默认选项白底，选中增加圆形选择点；正确增加勾号、绿色描边与解析。答错进入复活弹窗，不在选项提前提示正确答案。状态均通过文字、图标和颜色共同表达。禁用按钮统一中性灰，并保留各自的切角或胶囊轮廓。

列表、题卡、积分、榜单、证书、结算和复活使用同一游戏的皮肤变量。页面不展示其他游戏选择入口，跨游戏总证书不进入本轮玩家界面。

设计源可在 `设计源文件/组件规范.svg` 查看；运行时规范以 `共享源码/ui.css`、`games.js` 和 `app.js` 为准。题头与场景PNG可替换，文字与按钮不在图片内。后续美术修改应保留文字承载区域、当前透视和光源方向，避免将题头文字重新生成进位图。
