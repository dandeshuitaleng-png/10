# 带主题特征的统一横幅

用户指出上一轮红色、文脉横幅只有颜色差异，缺少主题线索。本轮保持同一折叠缎带家族，并按产业麦穗、生态山水的方式融入主题装饰。

- 十步芳草：红旗、纪念建筑与小星形，保持橙红主色。
- 千年文脉：展开书卷、竹简与书院屋檐，保持木棕主色，浅纸色辅助。
- 中央不绘文字，实际界面文字置于书写区；两侧装饰与缎带前后穿插。产业、生态原素材不改。

使用内置 `image_gen` 编辑现有 v2 横幅，产业与生态作为装饰组织和质感参考。精确提示词、各输入图的角色见 [prompts.json](prompts.json)。2172×724 透明源图为 `red-source.png`、`culture-source.png`；运行图缩放为 1050×350，使用 Sharp 调色板压缩，保留原始 alpha。没有用代码重绘或拼接主题装饰。

运行文件：`miniprogram/assets/red/banner-themed-v3.png`、`miniprogram/assets/culture/banner-themed-v3.png`。尺寸、轮廓、书写区与校验和见 [asset-manifest.json](asset-manifest.json)。原 v2 素材继续保留在 Git，但不进入运行主包。各独立主题包排除其他主题新横幅。

主界面、答题、须知弹窗与分享封面统一读取新资源；标题定位和胶囊避让按新轮廓重新计算。页面形式、配色体系、IP 与动作、业务进度和正式默认入口保留。
