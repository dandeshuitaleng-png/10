# 四主题横幅统一

依据用户 2026-10-21 截图中的反馈，将红色、文脉统一为后两个已确认横幅的折叠缎带形式。金色麦穗、绿色山水素材保持不变。

两张素材使用内置 ImageGen 对原参考进行编辑，完整提示词与引用顺序见 [prompts.json](prompts.json)。源透明 PNG 保留在本目录；尺寸、书写区和运行文件校验和见 [asset-manifest.json](asset-manifest.json)。运行文件为 `assets/red/banner-folded-v2.png`、`assets/culture/banner-folded-v2.png`，仅做尺寸与调色板压缩。原 `header.png` 继续保留，可从 Git 历史回看。

标题仍是实际界面文字，按新横幅中央书写区定位。主页、答题与弹窗使用同一素材；分享封面同步更新素材和标题坐标。

红色与文脉主页文字统一为 24px，以中文字形视觉中心校正光学偏移（-1.5px），原生截图检查上沿、下沿均留白。
