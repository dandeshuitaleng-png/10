# 趣味闯关管理平台界面规范

## 基础样式

|项目|约定|
|---|---|
|主色|橙红 #FF5027，用于查询、新增、保存、当前页签及选中菜单|
|背景|页面 #ECF1F5，顶部/侧栏/内容区白色|
|正文|#333；次级文字 #606266；辅助文字 #909399|
|边界|#EBEEF5，输入边框 #DCDFE6；圆角以2—4px为主|
|字体|苹方/微软雅黑；正文14px，侧栏15px，页面标题21px|
|布局|顶部64px、侧栏216px（收起64px），内容间距20—28px|
|控件|查询区输入框和操作按钮高36px；对话框默认控件使用Element Plus标准尺寸|

## 页面和操作

- 查询区位于表格上方，条件有明确标签。查询和回车提交，重置清空全部条件并回第一页。
- 页签只为已访问页面创建，首页不可关闭；页签切换恢复筛选和分页。
- 列表标题左对齐，新增等工具按钮靠右；较窄屏幕换行显示，不压缩标题。
- 查询/新增/保存为实色主按钮；导入/导出/下载模板/取消为描边按钮；查看/编辑/删除为文字操作。
- 导出当前已查询的全部结果，包含未显示在当前分页的数据。导入继续使用现有批次确认和整批校验逻辑。
- 表格表头浅灰，长题干省略并支持悬停查看，完整题面可从“查看”打开；操作列固定右侧，窄屏可横向滚动。
- 每页10/20/50条，支持跳页；删除后自动收回有效页码。
- 编辑弹窗包含取消、保存，点遮罩不会关闭。必填关键项以星号标记，数据校验失败不写入。
- 删除前确认；有关联子内容时继续阻止删除。游戏规则未保存时离开页面须确认。
- 小屏保持可滚动表格和可访问操作；减少动态效果偏好下关闭过渡。

只调整已存在的管理业务，参考图中的资源迁移、登录退出等不属于本项目功能，不添加无效入口。
