# 四主题 A 方案页面精修

延续甲方已确认的 A 方案：十步芳草为朱红、千年文脉为木棕、金色产业为麦金、青山绿水为山林绿。本轮不调整首页构图、原横幅、原人物和关卡坐标，完善配套页面的颜色、文字层次及控件细节。

## 已完成

| 位置 | 细化内容 |
|---|---|
| 答题章节提示 | 用对应主题色的细边和浅色渐变连接标题与题目，不新增人物或重复插画 |
| 解析 | 说明卡使用各自主题的浅色、边框和文字；正确选项保留绿色及对勾，避免仅靠颜色表示状态 |
| 未启用主按钮 | 四主题分别使用灰粉、灰棕、淡金和灰绿，取消全部使用同一灰绿的表现；启用态和按钮尺寸保持原样 |
| 我的学习 | 身份卡、徽章、学习统计与证书入口沿用对应主题边缘色和轻阴影；长昵称继续自然换行，不恢复装饰性 IP |
| 学习积分 | 积分数字采用等宽数字和分档字号；主题渐变卡与明细的边线、文字保持一致 |
| 排行 | 当前榜单使用主题浅底与强调边线；我的记录、高分数字和表头统一对应主题，排名列为多位数字留出位置 |
| 结果 | 完成标题与其他内页使用统一字体层次，正式荣誉证书继续保留既有版式与真实数据 |

源修改集中在 `pages/game/theme-details-20261022.wxss` 和 `components/game-button/index.wxss`，四套独立工程已同步。既有自然音效、音量设置、按钮重复反馈、选项边界及人物滚动修复继续保留。

## 验证记录

- 浏览器：四主题 × 320/375/430 CSS px × 十类页面，共 120 组。包含首页、答题、解析、学习、积分、空排行、复活、今日锁定、结果和证书页面；核对横向边界、44px 入口、52px 主按钮、当前关卡可见性、选项选中与提交启用，以及榜单切换。见 `qa/theme-details-20261022/browser-checks.json`。
- 微信模拟器：四主题各首页、答题、解析、学习、积分、空排行、复活和已获证书八类，共 32 组。原生 Canvas 证书图片均实际生成；核对选项边界与底部按钮位置。见 `native-checks.json` 及同目录完整截图。
- 回归：56 项测试通过，包含真实 Page 和服务、选项测量、按压、音频、证书、分享封面、人物动作和画布滚动。测试文件中的服务断言另有 JSON 记录，56 为 Node 测试运行器总项数，不将内部断言重复累加。见 `regression.log`。
- 编译：母工程与四套独立工程共五套 JavaScript/JSON、WXML、WXSS 检查通过，主包分别小于 2MiB。见 `compile-checks.json`。
- 正式工程保持固定主题入口、HTTP 连接、原 AppID 和既有关卡／判题／积分／获证规则；不新增四主题汇总入口，不恢复 B 方案。

浏览器使用隔离评审数据，原生证据来自本机微信模拟器。实体 iPhone／安卓微信本轮未复测；未上传微信体验版或发布。
