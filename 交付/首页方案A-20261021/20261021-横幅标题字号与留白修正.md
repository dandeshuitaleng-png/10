# 横幅标题字号与留白修正

针对“字体太大、超出横幅范围”的反馈，仅调整 A 方案横幅文字，保留四主题既有横幅图、配色、地图与人物动作。

| 页面 | 字号 / 行高 | 调整 |
|---|---|---|
| 首页、关卡页 | 20 / 24px | 四主题统一缩小字号，收紧字距，文字按横幅中央书写面定位 |
| 答题、学习、排行等内页 | 22 / 28px | 缩小标题行高，沿各主题书写面重新计算顶部偏移 |
| 须知、复活、锁定等弹窗 | 20 / 24px | 同步缩小，保持标题位于横幅中央 |

字号与行高由 `services-v4/home-layout.js` 统一返回，绑定到真实文字节点，防止历史主题 CSS 覆盖字号。未用裁切或隐藏文字处理溢出；标题完整显示，四个主题名称保持原文。

验证记录：`qa/home-designs-20261021/title-writing-area-checks.json`。使用微信渲染器的 320×568、375×812、430×844 约束容器，分别检查四主题的首页、答题与须知弹窗，共 36 组，36/36 通过。文字按中央书写面核对，不再仅以整张素材的外围边界作为判断依据。中文字形宽度采用完整 em 方框加字距的保守包络，纵向使用原生文字行框；这是布局检查，不是字形像素识别。375px 各页面另有原生截图，仅用于标题区域视觉复查；约束容器不作为整页人物定位或实体屏幕验收。对外四张首页图使用恢复宿主窗口尺寸后的独立截图。

母工程与四套独立工程同步修改。同源码浏览器入口和离线评审图同步更新；本轮没有新增实体手机验收，也未将 HTTP 源码校验视为浏览器视觉验收。
