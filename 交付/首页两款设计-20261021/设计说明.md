# 首页两款设计

直接打开“评审.html”，切换四个主题查看 A、B 两款。每张图均来自微信开发者工具实际页面。

- A「插画漫游」：以插画地图为主，顶部集中呈现进度与常用入口。
- B「智小谷导览」：以当前章节和智小谷导览卡片开场，地图收进圆角画框。

两款沿用原有主题横幅、插画、智小谷和对应主题色。四个主题仍是独立工程。

当前版已保留在 GitHub 的 main 分支及 baseline-20261021-before-home-options 标签中；新设计保存在 design/home-two-directions 分支，等待领导选型后再切换正式首页。

浏览器评审工具可体验相同源码中的章节入口。离线文件用于图片评审，手机微信的真机效果需继续复核。
