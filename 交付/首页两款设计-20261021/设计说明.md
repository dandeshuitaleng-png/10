# 首页两款设计

直接打开“评审.html”，切换四个主题查看 A、B 两款。每张图均来自微信开发者工具实际页面。

- A「插画漫游」：以插画地图为主，顶部集中呈现进度与常用入口。
- B「探索卡册」：按 Figma 图74强化故事卡册形式，以主题色底板、叠层纸卡、原场景画窗、主题编号签、问号封面和通关印章组成等大关卡卡册。智小谷在已到达卡面互动；按钮有渐变和按压反馈。

本轮按甲方原截图校正 B 配色：清亮浅底、白卡及原主题按钮渐变，编号与印章随主题变化。两款沿用原有主题横幅、智小谷和对应主题色；A 保留插画地图，B 使用等大故事卡册，原插画仅作为卡面画窗，无全屏路线或底座。四个主题仍是独立工程。

当前版已保留在 GitHub 的 main 分支及 baseline-20261021-before-home-options 标签中；新设计保存在 design/home-two-directions 分支，等待领导选型后再切换正式首页。

B 原参考：https://www.figma.com/design/WYrdxvwRhk0e7k1sj3mK4c/Untitled?node-id=1-67 。故事卡册图74：https://www.figma.com/design/WYrdxvwRhk0e7k1sj3mK4c/Untitled?node-id=1-76 。两张原参考图附在评审页，不是运行界面素材。

浏览器评审工具提供相同源码中的章节入口。本轮浏览器控制在 Work 设置中关闭，未记为本轮浏览器验收通过。离线文件用于图片评审，手机微信的真机效果需继续复核。
