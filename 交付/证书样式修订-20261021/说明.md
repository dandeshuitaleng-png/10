# 正式荣誉证书视觉修订（2026-10-21）

甲方提供的活动证书截图作为本轮样式参考。原证书偏人物展示卡，本轮统一改成竖版荣誉证书；四主题各自独立，不新增入口或主题选择页。

## 视觉

- 同一套版式：主题色厚外框、双层金色细边、米白纸面、内凹角花、右上与左下的浅金折带。
- 信息层级：平台名称 → 主题学习活动 → 荣誉证书 → 获证人 → 学习授予正文 → 主题称号 → 纪念语 → 平台与实际获证日期。
- 十步芳草用朱红框，千年文脉用木棕框，金色产业用麦金框，青山绿水用山林绿框；共同使用 `#FFFBF5` 纸面与 `#C7A25D` 金色。
- 证书内去掉原先悬浮的人物及信息卡结构。沿用页面的主题横幅、背景和按钮风格。
- 标题使用衬线字形，正文保持清晰易读；标准画布为 900×1280。长姓名、长称号和说明完整换行，必要时增加纸面高度，保留落款空间。
- 不复制参考截图里的“我的长征路”、个人昵称、活动日期或“长征先锋”称号。平台、实际获证人、称号、已颁发关卡范围和日期均来自既有数据；没有增加印章或新的颁发单位。

## 展示与保存

页面展示和“保存证书图片”共用同一份原生 Canvas 导出的 PNG，避免页面与相册证书两套排版。轻点证书可使用微信图片预览查看完整画面。生成失败或图片失效时提供重新生成；未获证仍显示原有领取条件，不提前发证。

`miniprogram/services-v4/certificate-art.js` 为可编辑绘制源，包含颜色、文案映射、换行、画布布局及边框绘制。页面只负责证书数据、生成状态、图片预览与相册保存。Canvas 绘制串行，切换证书时只接受当前证书的结果。

本轮没有变更题库、关卡数量、完成条件、积分、颁发接口、历史证书或存档结构。历史证书显示其颁发时记录的关卡范围，不随之后的关卡扩充而扩大。

## 验证与交付

- 64 项自动回归：证书绘制与实际 Page 流程、长姓名及长说明、预览和保存文件一致、图片失败重试；以及既有答题按压、声音、分享与四主题联网流程。
- 微信原生：四主题 × 320×568／375×812／430×932 共 12 组获证布局，4 组未获证状态和 1 组长姓名／长说明，共 17 项。包含原生 900×1280 PNG、预览比例、边界、底部按钮和落款滚动可达检查。
- 原生尺寸检查为隔离评审工程的容器与窗口参数，宿主模拟器仍为 390×844。实体 iPhone／安卓、实际相册权限、上传与发布不在本轮证据内。
- 母工程与四套独立工程编译、各主题主包体积、同步清单、回归记录与当前证书 PNG 一并交付。完整 ZIP 的大小不等于单个小程序主包体积。
