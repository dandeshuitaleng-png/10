# 趣味闯关

乡村文化知识答题项目，包含完整游戏体验版、服务端、管理端、微信小程序 UI 原型及视觉设计资料。

当前源码：v0.3.0 + 2026-10-14 排行榜补丁。补丁恢复本机连接，并使今日榜/总榜展示实际入账积分；沿用原数据库，不重算玩家奖励。

## 运行完整游戏

需要 Node.js 24.19 或更高版本，服务端使用内置 SQLite，无需安装第三方服务依赖。

```sh
cd demo
node server/start.cjs
```

- 游戏：<http://127.0.0.1:63112/web/play.html>
- 配套管理端：<http://127.0.0.1:63112/web/admin.html>
- 健康检查：<http://127.0.0.1:63112/api/health>

管理员凭据首次启动后随机生成，保存在工程外的 `.rural-quiz-runtime/.admin-credentials.json`。数据库、登录凭据和玩家存档不在仓库中；请勿提交运行数据。

微信开发者工具导入 `demo`，保持本机服务运行。`js/runtime-config.js` 的 `127.0.0.1` 地址仅供电脑本机体验，手机需使用其可访问的服务地址，正式环境需要获准 HTTPS 域名及真实身份、分享验证与同步接入。详见 [运行维护](demo/docs/full-development/OPERATIONS.md)。

## 其他模块

```sh
# Vue 后台界面原型
cd quiz-admin
npm ci
npm run dev

# 原生小程序的浏览器预览（独立 mock 展示）
cd rural-culture-miniprogram
node tools/serve.cjs
```

原生小程序在微信工具中导入 `rural-culture-miniprogram`；该原型当前展示配置为每章 3 题、60 秒，与完整游戏正式默认值不同。它不是正式规则变更。视觉资料也未自动替换完整游戏界面。

## 正式默认规则与验收状态

完整游戏初始实例为四主题、16 关，每关随机 10 题，单题 30 秒；超时算答错，每次挑战复活 1 次，北京时间零点解除日锁，首次通关发积分，正确率按首次作答统计。动态配置变更会撤销玩法批准；240 道源题仍待正式内容审核。

2026-10-13 基线通过 131 项自动测试、1434 项浏览器流程检查和 246 项动态配置检查。2026-10-14 排行榜补丁通过 26 项相关服务端检查，网页总榜及微信请求记录为一关、10 分、100% 正确率。旧完整浏览器/媒体/性能报告对应旧源码指纹，不自动成为补丁后重新验收结果；最新上传检查见 [UPLOAD-STATUS.md](UPLOAD-STATUS.md)。

微信模拟器曾通过实际触摸完成一关，但结算截图停在第 7 题，完整微信视觉流程仍未验收。真机视频、触摸、相册、帧率和内存，甲方接口、DM8/TongRDS、正式内容、培训及平台发布仍待对应证据。App Store 头部小游戏是质量目标，当前仓库不代表达到榜单品质或已经发布。
