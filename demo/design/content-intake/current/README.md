# 湖南乡村题库接入与内容检查

240题已从Excel「题库总表」重新读取，分为四主题、16关、每关15题。来源Excel和配套JSON没有修改。所有题目仍为待业务审核、未启用。

## 使用

[内容试玩页](index.html)可以切换全部16关，每次从该关15题中随机抽10题。可选、提交、查看正确反馈与解析；错误时分享复活仍未开放，可返回地图。展开审核区可查看本关全部题干、选项、答案和解析。本页只供内容审核与内部试玩，不写入正式积分、进度、榜单或证书。

题库没有图片。文字题不补无关风景图，原手绘环境仅作装饰背景。主题名称和四级难度保持原规则。

## 编辑与重新导入

在原Excel总表修改题目。内容负责人审核通过后，填写审核状态「已通过」，启用状态「启用」，并在审核意见记录审核人、日期和结论。审核状态和启用状态各自生效，不因导入自动改成通过。

从demo目录执行：

```sh
node scripts/import-question-bank.cjs --install
node scripts/build-preview.cjs
node --test tests/*.test.cjs
```

默认读取相邻「题库交付/湖南乡村知识题库240题」中的Excel和JSON元数据。可用 `--workbook`、`--base` 指定来源，`--output-dir` 指定独立检查目录。导入器读取Excel最新题目，并核对答案缓存、来源映射、重复编号、四选项、主题和关卡对应；异常时不覆盖现有正式题池。

只有已通过、已启用且审核意见非空的题目进入可用池；单关不足10题不输出该关，不借用其他关卡。`bank.json`保留全部题目用于本页审核；`approved-pools.json`与主工程`js/data/approved-pools.js`只包含可用关卡。当前可用关卡为0，这是审核状态的结果。
