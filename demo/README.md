## 开始体验

使用 Node.js 24.19 或更高版本，在本目录运行：

```sh
node server/start.cjs
```

打开 http://127.0.0.1:63112/web/play.html；后台为 http://127.0.0.1:63112/web/admin.html。首次启动自动生成随机管理员凭据，保存于 `../.rural-quiz-runtime/.admin-credentials.json`（仅本机可读），不提供通用默认密码。也可通过 `QUIZ_ADMIN_USERNAME`、`QUIZ_ADMIN_PASSWORD` 环境变量配置，密码至少12位。

体验账号与进度保存在本机数据库。浏览器与微信通过各自的随机设备凭据恢复体验账号；没有跨设备身份同步。清除浏览器存储或微信数据会失去本机恢复凭据，请不要以此测试恢复。

## 已实现功能

- 十步芳草、千年文脉、金色产业、青山绿水，每主题4关；逐关解锁与地图进度。
- 每关随机10题、4选项。单题30秒，超时算错，每次挑战1次复活；复活后再错，仅当前关卡当日锁定，北京时间零点解除。
- 正确反馈与解析、图片失败重试、原创示意视频、退出恢复、重玩、分享邀请。
- 首次通关按10/15/20/30分入账，总计300分；日榜、总榜，按关数与首次作答正确率排序。
- 四主题证书与“乡村知识闯关王”总证书。网页下载SVG；微信根据服务端已获得记录生成PNG并预览/申请保存相册。
- 五项管理模块，主题/关卡新增、名称与排序、启停、每关题数和积分、复活额度、每日积分上限、证书/分享文案与素材配置；题库增删改查、审核、独立题库及活动JSON导入导出、操作与同步记录。
- 稳定主题/关卡ID，进行中的挑战冻结题目、计时、复活、奖励、日上限和证书条件；迁移保留旧进度、积分和已发证书。配置变更不会重算旧积分。
- 浏览器将已获证书生成PNG，系统支持时可从明确按钮分享，不支持时可保存后转发；微信基于已获记录生成PNG并打开系统分享。系统分享完成未被用作可信复活证据。
- 320px短屏滚动、44px操作区域、键盘操作、音效与减少动画偏好。

上述30秒、一次复活、首次发分等初始规则来自用户2026-10-12的直接确认。动态配置变更会撤销玩法批准；有限日上限按剩余额度截断奖励、额度用尽仍通关，多次复活按挑战额度耗尽后再错日锁，这些扩展策略仅为未批准的体验设置。默认不设置日上限，默认一次复活不变。体验版复活须明确确认测试复活；分享邀请成功不自动冒充可信分享验证。原题库内容保留，题库审核流程现已取消。

## 微信开发者工具

导入本目录，保留原AppID。`js/runtime-config.js` 当前指向本机 `http://127.0.0.1:63112`。电脑模拟器可连接本机服务；手机真机需另外配置手机可访问的服务地址，正式版必须使用获准HTTPS域名与可信身份/分享验证。此工程没有上传或发布到平台。
