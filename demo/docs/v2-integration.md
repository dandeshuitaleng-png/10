# V2已确认画面的工程接入

日期：2026-10-07。用户先确认“可以，效果还可以”，随后授权继续接入。该确认更新了key-screens-round04中先前“待用户确认”的阶段状态；不代表90分或设备验收通过。

## 已接入

- Canvas首页使用四组统一手绘入口，保持2×2和各主题进度位置。原V1图片与全部设计源保留。
- 生态地图使用新背景；S形路线、四关节点与文字独立绘制。其他三主题仍显示场景待制作，未替换成冒充正式内容的生态地图。
- 按钮与节点加入按下反馈。固定按钮为52逻辑像素，在320px宽窗口约44.37px。
- 题干与选项自动换行；内容可触摸拖动或鼠标滚轮滚动，页尾确认按钮固定。拖动不会误选答案，部分可见选项只有触控区域满足44px才加入可点击区域。
- 答对显示反馈，再点击下一题；10题全对进入实际试玩结果。错误显示复活弹窗、未验证分享不授予复活，锁定状态提供返回地图。
- 媒体来自题目media字段。图片失败提供重试；不存在无关风景填充。真实示例题没有强行添加装饰图，图片分支用隔离测试样例验证。
- 新资产5张约839KB（详见v2-asset-sizes.json）；设计原图保留，运行素材仅调整分辨率与压缩。

## 验证结果

- 17项单元/框架测试通过，包括四主题16关、题库与规则边界、生命周期、点击取消、拖动防误选、一次复活及锁定状态机。
- 26项实际浏览器流程断言通过：连续十题、正确反馈、重玩、答错与未验证分享、返回地图、四尺寸长题末项及触控区域、隔离验证器下再次答错锁本关。
- 指针实际拖动、拖动不选中、媒体加载及媒体失败4项检查通过。
- 浏览器截图在design/playtest-v2，结果在report.json及media-gesture-report.json。作者已目视检查首页、生态地图、题面、小屏长题末尾、复活、结果页。

正式题库仍为空；试玩只随机抽取12道生态示例中的10题。没有写入正式积分、关卡进度或证书，也不会因试玩完成解锁正式第二关。地图正式数据仍为0/4，是当前未接后端的事实，不是完整16关已交付。

时限、超时、每日边界、准确率分母与重复积分继续待确认；试玩结果展示真实答对题数/作答次数，不生成未知口径的正式正确率。
