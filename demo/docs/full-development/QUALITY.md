# 游戏体验与视觉质量计划 · 2026-10-13

## 产品与边界

面向手机与 PC 的乡村知识四选一小游戏。用户的主要任务是选择四主题之一，完成每关十题，查看知识解析和旅程进度，领取主题证书。使用已确认的四主题插画与地图，不新增体力、道具、星级等玩法。App Store 头部小游戏只作为清晰度、反馈与完成度的质量参照，不宣称排名或达到外部榜单标准。

0.3.0支持动态目录，四主题16关保留为初始实例。原主题原四关使用原画坐标；新增主题或不同关数使用对应配置素材与可滚动旅程地图，避免塞入不存在的原地标。新增主题不自动获得原创场景品质。扩展策略与实际新取值不自动继承正式批准；见 [合同补齐记录](CONTRACT-1012-GAPS.md)。

## 紧凑视觉系统

- 纸色 `#EFEAD9`：地图外层与阅读背景；卡片白 `#FFFCF0`：明确可读区域。
- 深林 `#263D34`：正文与主标题；湖蓝 `#176B80`：主要动作与进度。
- 稻金 `#E89246`：当前关卡、印章与奖励；陶红 `#9D4B31`：超时提醒与未通过状态。
- 主标题：系统楷体（Kaiti SC / STKaiti）少量用于旅程首页与证书；正文：PingFang SC / Microsoft YaHei；数据：系统等宽字体。延续现有画面，字级保持明确。
- 布局：固定标题与操作区，长内容在两者之间滚动；题干与选项形成一个阅读流。功能入口与题目按钮至少 44 物理像素高。
- 识别元素：四主题插画扉页配一条四关旅程进度，五枚证书印章串成同一收集体系。证书承接实际主题完成条件，不制造额外游戏规则。

```
首页                 题面                 证书
┌旅程标题 / 积分┐   ┌题号 / 30秒环┐    ┌我的旅程印章┐
│插画入口 插画入口│   │题干 / 图片    │    │主题证书 / 条件 │
│插画入口 插画入口│   │A / B / C / D │    │主题证书 / 条件 │
└榜单 / 证书 / 继续┘   └退出 / 确认答案┘    └总证书 / 返回   ┘
```

计划自评：舍弃通用金币、宝箱、勋章装饰，以已确认的乡村插画与地图作为识别核心。排行榜优先展示完成关数和首次作答正确率，积分只作为真实奖励补充。使用短句表达操作与后果。

## 交互准则

单题 30 秒，低于 5 秒显示温和明确的倒计时强调；服务器裁定超时。答对后呈现知识解析，用户确认后进入下一题。一次分享复活重答当前题，体验环境明确写“体验版使用测试复活”。退出保存当前挑战并提示倒计时仍继续。按北京时间零点解除当日锁定；首次通关发分，重玩不重复积分；正确率统计首次作答。

提交与远程加载显示状态并防止重复动作；连接失败提供重试和返回路径。所有滚动区域在短屏可拖动查看，不把被裁切的控件作为有效热点。网页需要为 Canvas 热点提供键盘可操作的等价控件与清晰焦点，计时只在关键时刻播报。尊重 reducedMotion；动效只服务按压、状态反馈与结算，背景保持静止。

## 验证证据

OnlineRenderer 独立于原试玩 Renderer，旧试玩验证不应被此变更影响。静态渲染验证覆盖首页、四主题地图、准备、文字/图片/长题、复活、退出、日锁、结算、排行榜、五证书、设置与错误状态，以及 320×568、375×812、430×932 尺寸；实际浏览器运行、键盘路径、联网持久化与设备验证分别记录，不把结构测试视作视觉验收。

2026-10-13本轮：131项功能、状态与服务端测试全部通过。实际Chrome测试通过1434项过程断言，输出55张画面；四主题16关真实作答、300积分、5证书、重玩、断网重试、响应丢失幂等重试、会话恢复、五模块管理实际增改审删/导入导出与配置传递均覆盖。媒体专项10项检查通过，实际完成30题，覆盖2张相关示意配图与1段原创6秒动画、图片失败重试、视频解码播放/关闭与原计时保留。

作者逐张审视关键首页、地图、准备、文字/图片/视频题、结果、榜单、证书与短屏复活/锁定，以及1366px与320px后台。浏览器分辨率覆盖320×568、375×812、414×896、430×932、1024×768；后台覆盖1366×900、375×812、320×568。结果是本轮功能与作者视觉检查，不代替10–12岁/13–16岁目标玩家试玩、真实手机、平台审核或独立专业验收。

浏览器证据：[主流程记录](../../design/full-development/evidence/browser-report.json)、[媒体记录](../../design/full-development/evidence/media-report.json)。测试数据库隔离，源库仍保留待审核状态。测试断言数包含每次按钮可达性检查，不等于1434个独立测试用例。

质量参照依据：[Apple游戏设计](https://developer.apple.com/design/human-interface-guidelines/designing-for-games/)、[游戏操作](https://developer.apple.com/design/human-interface-guidelines/game-controls)、[动效](https://developer.apple.com/design/human-interface-guidelines/motion)。用明确反馈、操作安全区、短屏可达与减少动画作为可验指标；App Store头部榜单不作为完成证明。

微信模拟器证据范围见 [本轮记录](../../design/full-development/evidence/wechat-report.json)，原生确认、视频与相册真机路径未作最终验收。
