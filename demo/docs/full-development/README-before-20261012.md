## 保留的工程能力

```text
game.js                     微信入口
game.json                   竖屏运行配置
project.config.json         原AppID与工具配置；设计/测试文件不进入游戏包
project.private.config.json 原个人配置，保持不变
js/
  main.js                   启动、生命周期与模块组合
  core/                     页面路由、逻辑视口、触摸输入
  platform/wechat.js        微信平台适配
  data/                     四主题、16关、积分和待确认规则；正式题池入口
  services/                 资源、偏好存储、音频、后端接口
  ui/                       设计令牌、绘制工具、页面渲染
images/                     原V1资产与压缩后的V2运行资产；不含按钮与文字
audio/                      预留正式音频位置
design/                     风格板、画面、可编辑预览及独立设计数据
docs/                       需求快照、美术规范、接口边界、检查和清理记录
scripts/                    预览构建与设计导出
tests/                      工程框架检查
```

移除内容包括敌机、玩家飞机、子弹、碰撞/射击/刷怪/飞机分数状态、爆炸帧图、旧背景和未使用的样例辅助模块。原模板完整备份位置与逐项清理记录见[cleanup.json](docs/cleanup.json)。
