# 趣味闯关 · Day 1美术提案

日期：2026-10-07。状态：提案，待用户审阅；未通过最终美术或设备验收。

## 方向

少年乡村知识探索。湖蓝与暖橙的平面套色插画，采用清楚的瓦屋、田块、山形与河道轮廓，适量印刷边缘质感。识别母题为一条连起乡村场景的小路；地图路径与节点属于独立可编辑UI。

不使用塑料3D、立体金字、镜面/发光、果冻按钮或低龄大眼角色。主视觉目前没有引入角色或新增收集系统。场景为通用乡村示意，不代表某个已核实的历史遗址、具体物产或生态地点。

## 令牌

| 用途 | 色值 | 规则 |
| --- | --- | --- |
| 主行动 | #176B80 | 开始、确认、继续；浅色字 |

| 全局底 | #F5F3E9 | 暖纸白 |
| 内容底 | #FFFEF9 | 题目、选项、弹窗 |
| 主文字 | #203D43 | 标题、题干、控件文字 |
| 辅助文字 | #587079 | 说明和次要信息 |
| 选中底 | #DBEBE9 | 结合描边和选项标识，不只靠颜色表示 |

主色家族为湖蓝、暖橙和暖纸白，墨色与灰色作中性信息色。卡片/弹窗16圆角，按钮/选项12圆角；一层浅描边或压下阴影。原生绘制文字使用系统中文无衬线字体；标题32—34/700，题干24/600，选项16，辅助14—16。具体字号和笔触必须继续真机检查，不能仅凭数值通过。
