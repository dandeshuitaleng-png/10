# 续作：生态十题试玩验收

日期：2026-10-07。未改动四主题、16关的正式需求。

## 已完成

- 微信入口与浏览器预览复用同一App、Renderer、Input及Challenge模块。
- 首页明确提供“试玩10题”，从12道生态示例题随机抽10道，不重复。
- 四选一、选中反馈、确认、题号和进度更新；十题全部答对后显示结果、重玩与返回地图。
- 旧题重复提交不增加成绩；答错停留当前题，复活请求并发保护，取消/失败/离开后迟到响应不授予复活。
- 本地状态机支持验证器确认后恢复原题、保留此前正确题，再错仅锁当前挑战；通过自动测试验证。实际试玩没有配置验证器，因此无法真正复活，也不会触发第二次错误锁定。
- 试玩题库与正式QUESTION_POOLS分开；不授予正式积分、关卡进度、排行榜名次或证书。
